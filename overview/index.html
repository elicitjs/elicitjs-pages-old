Overview

Elicit.js builds elicitation interfaces from charts. People drag a bar or place a point, and you get structured data back. An interface is built through a declarative spec, Elicit(spec): one schema, one dataset, and a list of marks. Every example on these pages runs the code beside it. Core concepts explains the model.

API reference

Elicit(spec)

The entry point (elicit.Elicit). Builds a dataset and one chart over it from one spec, and returns the chart. Append chart.dom() to the page. The spec takes the dataset keys and the chart keys below. For several charts over one dataset, call Elicit.dataset and ds.chart instead — see Datasets & linked charts.

Elicit({ schema, data?, marks, width?, height?, … }) → Chart
parent.append(chart.dom())
Elicit.dataset({ schema, data?, … }).chart({ marks, … })   // the same thing, in two calls
Returns / emits

A Chart, which also carries the dataset’s methods. The dataset deep-copies data and owns it; marks re-derive from the committed rows on every render.

The dataset

What Elicit.dataset returns. It reads and writes the data from outside any chart, and every chart over it redraws on a change. A chart carries the same methods, so chart.getData() is chart.dataset.getData().

ds.setData(data) → void
ds.setDomain(field, domain, { table? }) → boolean
ds.set(field, value, { index?, table? }) → boolean
ds.on("change" | "select", cb) → () => void
ds.undo() · ds.redo() · ds.canUndo() · ds.canRedo()
ds.select(i) · selectWhere · toggleSelection · selectAll · clearSelection
ds.getSelection() · ds.getSelectionAll()

OptionTypeDescription
chart(spec)
→ Chart
A chart over this dataset. Make as many as you need. See Datasets & linked charts.
getData()
→ Datum[]
A deep copy of the committed data — the elicited answer. Copy, because handing out the live rows would let a caller mutate past every constraint the dataset just enforced.
getSchema()
→ Schema
A deep copy of the dataset’s schema, including any domain an editable axis reshaped. Your original spec.schema is never mutated.
setData(data)
void
Replace the rows and redraw every chart. Bypasses constraints — it is a trusted seed or reset, not an edit — and clears the undo history for the same reason.
setDomain(field, domain)
→ boolean
Set a field’s domain, for a zoom button or a reset. One undo step; null restores the declared domain. Every chart shares the domain. See Zoom & pan.
set(field, value, options?)
→ boolean
Write one cell from outside any chart. Runs the dataset’s constraints and the lock; one undo step. See Write from outside a chart.
on(type, cb)
→ unsubscribe
change fires once per commit with the new data; select fires when the selection moves. Returns a function that removes the listener.
undo() / redo()
→ boolean
Step one gesture, whichever chart it happened in, and report whether they moved. See History & keyboard.
select(i) / selectWhere / toggleSelection / selectAll / clearSelection
→ boolean
Set which rows are selected, by index or by a field match. Every chart shows the selection. See Selection.
getSelection() / getSelectionAll()
→ number | number[]
The selected row, and every selected row when the selection is multiple.
Returns / emits

change is the seam to the rest of your app: a survey posts getData() on submit, a live app writes it through on every commit.

The chart

What Elicit and ds.chart return: a plain object, not a DOM node. dom() is the node to append. It carries every dataset method above, plus its own.

The chart's container. Append it where you like; it is the same node on every call.

The dataset this chart reads and writes. For Elicit(spec), the one built from the same spec.

A minimal chart

Three pieces make a static chart: schema (what each field is and its domain), data (the rows), and marks (how those rows are drawn). An edit makes it interactive.

A bar mark

schema + data + bar({ channels }). x is a band of categories, y a linear value, fill a constant.

const chart = Elicit({
  width: 380, height: 240,
  margins: { top: 16, right: 16, bottom: 28, left: 34 },
  data: [
    { cat: "A", n: 30 }, { cat: "B", n: 55 },
    { cat: "C", n: 22 }, { cat: "D", n: 44 },
  ],
  schema: {
    cat: { type: "categorical", domain: ["A", "B", "C", "D"] },
    n:   { type: "quantitative", domain: [0, 60] },
  },
  marks: [
    bar({
      fill: "#50AEB7",
      channels: {
        x: { field: "cat" },
        y: { field: "n" },
      },
    }),
  ],
});
mount(chart.dom());

Encoding, and its inverse

Attach an edit to a channel and a gesture writes that channel back through the same scale. The bar below matches the one above, except y now carries edit: move(). Encoding maps data to height; the edit maps a drag back to data.

The same bar, now editable

y carries edit: move(). Dragging a bar writes its value back to the data.

const chart = Elicit({
  width: 380, height: 240,
  margins: { top: 16, right: 16, bottom: 28, left: 34 },
  data: [
    { cat: "A", n: 30 }, { cat: "B", n: 55 },
    { cat: "C", n: 22 }, { cat: "D", n: 44 },
  ],
  schema: {
    cat: { type: "categorical", domain: ["A", "B", "C", "D"] },
    n:   { type: "quantitative", domain: [0, 60] },
  },
  marks: [
    bar({
      fill: "#50AEB7",
      channels: {
        x: { field: "cat" },
        y: { field: "n", edit: move() },
      },
    }),
  ],
});
mount(chart.dom());
Try: Drag a bar up or down.

Reading the answer

Read committed data through onChange, getData(), or chart.on("change", …). These fire only when an edit finishes, so hover previews are excluded.

onChange / getData

onChange logs each commit. getData() returns a deep copy of the elicited rows. on("change") subscribes a listener to the same commits.

const chart = Elicit({
  width: 380, height: 240,
  margins: { top: 16, right: 16, bottom: 28, left: 34 },
  data: [
    { cat: "A", n: 30 }, { cat: "B", n: 55 },
    { cat: "C", n: 22 }, { cat: "D", n: 44 },
  ],
  schema: {
    cat: { type: "categorical", domain: ["A", "B", "C", "D"] },
    n:   { type: "quantitative", domain: [0, 60] },
  },
  onChange: (d) => console.log("elicited", d),
  marks: [
    bar({
      fill: "#50AEB7",
      channels: {
        x: { field: "cat" },
        y: { field: "n", edit: move() },
      },
    }),
  ],
});
mount(chart.dom());
// chart.getData()  — deep copy of the committed rows
// chart.on("change", (d) => …)  — same commits, as a listener
Try: Drag a bar — open the console to see the committed rows.
