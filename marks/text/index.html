Text

text draws one label per row at (x, y). format sets how a number displays, as a d3-format string or a function, without changing the data. It takes the universal edits (move(), cycle(), rotate()), and editText() lets you retype a label.

API reference

text(options) · textX(options) · textY(options)

Import from elicit.plot. text positions from x AND y; textX / textY are 1-D labels along one axis (the other parks at centre).

text({ channels, orientation, format, wrap, lineHeight, edits, id }) → Feature
textX(options) → Feature   // value on x
textY(options) → Feature   // value on y
Options
OptionType · defaultDescription
channels
objectdefault{}
Channel map. See Channels.
orientation
'vertical' | 'horizontal'defaultauto
Which axis the value runs along ('vertical' = y). Inferred from a band scale or the lone bound channel; textY / textX pin it.
text, fontSize, textAnchor, lineAnchor, dx, dy
shorthand
Constant shorthands, e.g. text({ dy: -8, lineAnchor: "bottom" }).
format
string | fndefaultString
Display formatter: a d3-format string (e.g. ".1f") or (v) => string. Display-only — the field stays raw. Helpers live on format (format.number, format.percent, …).
wrap
number | fn
Wrap the label at this pixel width. A function (d, i, data) => number gives a per-datum width, for a label that has to fit the box it sits in.
lineHeight
numberdefault1.35 × fontSize
Pixel step between wrapped lines.
edits
Edit[]
Mark-level edits; per-channel edits live in channels[ch].edit.

A feature emitting one text per datum.

Labels from data

x/y position the label, and text is its string. text, fontSize, textAnchor, lineAnchor, dx and dy take a field or a constant and are used as-is. angle is in degrees. Offset and anchor keep a label clear of the mark it labels.

A labelled scatter

point for the dots, text for the labels above them — dy + lineAnchor park the string above the point.

mount(Elicit({
  width: 360, height: 260,
  margins: { top: 16, right: 16, bottom: 28, left: 34 },
  data: [
    { gdp: 3, life: 6, name: "Ada" },
    { gdp: 6, life: 8, name: "Grace" },
    { gdp: 8, life: 4, name: "Alan" },
  ],
  schema: {
    gdp:  { type: "quantitative", domain: [0, 10] },
    life: { type: "quantitative", domain: [0, 10] },
    name: { type: "categorical", domain: ["Ada", "Grace", "Alan"] },
  },
  marks: [
    point({ fill: "#50AEB7",
      channels: { x: { field: "gdp" }, y: { field: "life" } } }),
    text({ fontSize: 12, dy: -10, lineAnchor: "bottom",
      channels: {
        x: { field: "gdp" }, y: { field: "life" },
        text: { field: "name" },
      } }),
  ],
}))

Formatted numeric labels

format is display-only (a d3-format string or a helper from format.*). The field stays the raw number, so a later drag still inverts correctly.

mount(Elicit({
  width: 360, height: 240,
  margins: { top: 16, right: 16, bottom: 28, left: 34 },
  data: [
    { cat: "A", n: 0.42 },
    { cat: "B", n: 0.75 },
    { cat: "C", n: 0.18 },
  ],
  schema: {
    cat: { type: "categorical", domain: ["A", "B", "C"] },
    n:   { type: "quantitative", domain: [0, 1] },
  },
  marks: [
    barY({ fill: "#1B3F60",
      channels: { x: { field: "cat" }, y: { field: "n" } } }),
    text({ fontSize: 12, dy: -6, lineAnchor: "bottom",
      format: format.percent(".0%"),
      channels: {
        x: { field: "cat" }, y: { field: "n" },
        text: { field: "n" },
      } }),
  ],
}))

Line chart with value labels

lineY draws the series; text sits on the same (x, y) with dy above each point.

mount(Elicit({
  width: 400, height: 260,
  margins: { top: 20, right: 16, bottom: 28, left: 34 },
  data: [
    { t: 0, n: 40 }, { t: 1, n: 62 }, { t: 2, n: 48 },
    { t: 3, n: 78 }, { t: 4, n: 60 }, { t: 5, n: 84 },
  ],
  schema: {
    t: { type: "quantitative", domain: [0, 5] },
    n: { type: "quantitative", domain: [0, 100] },
  },
  marks: [
    lineY({
      stroke: "#50AEB7", strokeWidth: 2.5, curve: "catmullRom",
      channels: { x: { field: "t" }, y: { field: "n" } },
    }),
    text({
      fontSize: 11, dy: -10, lineAnchor: "bottom",
      fill: "#2A7880", format: ".0f",
      channels: {
        x: { field: "t" }, y: { field: "n" },
        text: { field: "n" },
      },
    }),
  ],
}))

Editing labels

A direct-pick edit makes a label interactive. Use the universal edits to drag, rotate or cycle a label, or editText() to retype its content.

Drag to reposition

Mark-level move({ channels: ["x","y"] }) moves the label and writes x/y back through the scales. Attach an edit on a channel or in <code class="inline">edits</code>.

mount(Elicit({
  width: 360, height: 240,
  margins: { top: 16, right: 16, bottom: 28, left: 34 },
  data: [
    { x: 3, y: 4, label: "drag me" },
    { x: 6, y: 7, label: "and me" },
  ],
  schema: {
    x: { type: "quantitative", domain: [0, 10] },
    y: { type: "quantitative", domain: [0, 10] },
    label: { type: "categorical", domain: ["drag me", "and me"] },
  },
  marks: [
    text({ fontSize: 13, fill: "#2A7880",
      channels: {
        x: { field: "x" }, y: { field: "y" },
        text: { field: "label" },
      },
      edits: [ move({ channels: ["x", "y"] }) ],
    }),
  ],
}))
Try: Drag a label to move it.

Draggable numeric readout

text and y read the same field, and move() on y rewrites it, so the number updates as you drag. format sets how it displays.

mount(Elicit({
  width: 360, height: 260,
  margins: { top: 16, right: 16, bottom: 28, left: 40 },
  data: [ { cat: "A", n: 40 }, { cat: "B", n: 70 } ],
  schema: {
    cat: { type: "categorical", domain: ["A", "B"] },
    n:   { type: "quantitative", domain: [0, 100] },
  },
  marks: [
    text({ fontSize: 16, fill: "#1B3F60", format: ".1f",
      channels: {
        x: { field: "cat" },
        y: { field: "n", edit: move() },
        text: { field: "n" },
      } }),
  ],
}))
Try: Drag the number up or down.

Type to edit content

editText() wires double-click-to-retype: an inline input opens, Enter commits, Esc cancels.

mount(Elicit({
  width: 360, height: 220,
  margins: { top: 16, right: 16, bottom: 28, left: 34 },
  data: [
    { x: 3, y: 5, label: "double-click" },
    { x: 7, y: 3, label: "me too" },
  ],
  schema: {
    x: { type: "quantitative", domain: [0, 10] },
    y: { type: "quantitative", domain: [0, 10] },
    label: { type: "categorical" },
  },
  marks: [
    text({ fontSize: 14, fill: "#5B4A96",
      channels: {
        x: { field: "x" }, y: { field: "y" },
        text: { field: "label", edit: editText() },
      } }),
  ],
}))
Try: Double-click a label, type, and press Enter.

Drag and retype together

Mark-level drag plus editText on the text channel: drag repositions, double-click retypes.

mount(Elicit({
  width: 360, height: 220,
  margins: { top: 16, right: 16, bottom: 28, left: 34 },
  data: [
    { x: 3, y: 5, label: "move me" },
    { x: 7, y: 3, label: "rename me" },
  ],
  schema: {
    x: { type: "quantitative", domain: [0, 10] },
    y: { type: "quantitative", domain: [0, 10] },
    label: { type: "categorical" },
  },
  marks: [
    text({ fontSize: 14, fill: "#8F6511",
      channels: {
        x: { field: "x" }, y: { field: "y" },
        text: { field: "label", edit: editText() },
      },
      edits: [ move({ channels: ["x", "y"] }) ],
    }),
  ],
}))
Try: Drag to move; double-click to rename.
