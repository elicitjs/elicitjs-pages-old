Shape

shape() draws one SVG path per row, centred at its x/y — a named shape, a pictogram, any path you write. The shape comes from a symbol channel or the path option; size is the radius of the box it fits, and angle turns it in place. It takes every universal edit, as point does.

API reference

shape(options)

One SVG path per row, centred at x/y. The shape comes from a symbol channel or the path option. It takes every universal edit, is picked inside its body, and declares a node box for a network.

shape({ channels, path, edits, id, table, tip }) → Mark
Options

path
string | (d, i, data) => stringdefault'circle'
The shape when no symbol channel is declared: a shape name, an SVG path, or a function of the row returning either. A string that is neither draws a circle and logs a warning.

objectdefault{}
Channel map — see Channels.

Shorthands for constant channels.

The shape's centre. Omitted, it sits at the middle of the plot on that axis.

Named shapes by category

Put a categorical field on symbol and each category takes a named shape: circle, square, triangle, diamond, star, cross, wye, in that order. legends: true keys each category with its shape.

You can grab a shape anywhere inside its outline.

Trees by species

symbol on a categorical field maps each species to a named shape; the legend keys them.

const chart = Elicit({
  width: 440, height: 280,
  margins: { top: 16, right: 16, bottom: 32, left: 36 },
  legends: true,
  schema: {
    x: { type: "quantitative", domain: [0, 100] },
    y: { type: "quantitative", domain: [0, 100] },
    kind: { type: "categorical", domain: ["oak", "pine", "birch", "maple"] },
  },
  data: [
    { x: 18, y: 30, kind: "oak" },   { x: 30, y: 72, kind: "pine" },
    { x: 46, y: 48, kind: "birch" }, { x: 62, y: 80, kind: "maple" },
    { x: 74, y: 26, kind: "oak" },   { x: 86, y: 58, kind: "pine" },
  ],
  marks: [
    shape({
      size: 9, fill: "#1B3F60",
      channels: {
        x: { field: "x" },
        y: { field: "y" },
        // Each category takes a named shape: circle, square, triangle, diamond, …
        symbol: { field: "kind", edit: cycle() },
      },
      edits: [move({ channels: ["x", "y"] })],
    }),
  ],
});
mount(chart.dom());
Try: Drag a shape to move it · click one to cycle its species.

Pictograms from SVG paths

Give symbol a scale: { range: [...] } of SVG path strings, and each category draws its own pictogram. A path can use any coordinates. It is fitted to the box of radius size around its row's position.

The elicited value is the category. The path encodes it, as a colour does on fill.

Rank three needs

A path per category on the symbol scale; move() on y sets each priority.

// Hand-written SVG paths, one per category. Any coordinates work:
// each path is fitted to a box of radius `size` around its row's x/y.
const house = "M0 10 L10 0 L20 10 L17 10 L17 20 L3 20 L3 10 Z";
const car = "M1 12 L4 6 L16 6 L19 12 L19 16 L1 16 Z M4 16 A2 2 0 0 0 8 16 Z M12 16 A2 2 0 0 0 16 16 Z";
const heart = "M10 18 L2.5 10 A5 5 0 0 1 10 4.5 A5 5 0 0 1 17.5 10 Z";

const chart = Elicit({
  width: 380, height: 260,
  margins: { top: 20, right: 16, bottom: 32, left: 36 },
  schema: {
    need: { type: "categorical", domain: ["housing", "transport", "health"] },
    priority: { type: "quantitative", domain: [0, 10] },
  },
  data: [
    { need: "housing", priority: 7 },
    { need: "transport", priority: 4 },
    { need: "health", priority: 8 },
  ],
  marks: [
    shape({
      size: 16,
      channels: {
        x: { field: "need" },
        y: { field: "priority", edit: move() },
        symbol: { field: "need", scale: { range: [house, car, heart] } },
        fill: { field: "need", scale: { range: ["#4e79a7", "#f28e2b", "#e15759"] } },
      },
    }),
  ],
});
mount(chart.dom());
Try: Drag a pictogram up or down to set its priority.

One path for every row

With no symbol channel, the path option sets the shape: a name, an SVG path, or (d, i, data) => string for a shape chosen per row. It defaults to "circle". A string that is neither a name nor a readable path draws a circle and logs a warning.

angle rotates the shape in degrees, counter-clockwise from east. rotate() on angle turns it about its centre, and resize() on size grows it. Both read the same drag, so when separates them: with when.noShift and when.shift, a plain drag turns an arrow and Shift-drag sets its speed.

Wind arrows

path sets one arrow for every row; rotate() writes dir and resize() writes speed.

// Wind at three stations: drag an arrow to turn it, Shift-drag to set its speed.
const arrow = "M0 7 L12 7 L12 2 L20 10 L12 18 L12 13 L0 13 Z";   // points right (0°)

const chart = Elicit({
  width: 400, height: 260,
  margins: { top: 16, right: 16, bottom: 32, left: 36 },
  schema: {
    x: { type: "quantitative", domain: [0, 100] },
    y: { type: "quantitative", domain: [0, 100] },
    dir: { type: "quantitative", domain: [0, 360] },
    speed: { type: "quantitative", domain: [0, 30] },
  },
  data: [
    { x: 22, y: 62, dir: 30, speed: 12 },
    { x: 52, y: 34, dir: 120, speed: 20 },
    { x: 80, y: 70, dir: 300, speed: 6 },
  ],
  constraints: [clamp({ field: "speed", min: 2, max: 30 })],
  marks: [
    shape({
      path: arrow,
      fill: "#50AEB7",
      channels: {
        x: { field: "x" },
        y: { field: "y" },
        // Degrees, counter-clockwise from east.
        angle: {
          field: "dir",
          scale: { range: [0, 360] },
          edit: rotate({ pick: "direct", pivot: "mark", fold: false, when: when.noShift }),
        },
        size: { field: "speed", scale: { range: [4, 28] } },
      },
      edits: [resize({ channel: "size", when: when.shift })],
    }),
  ],
});
mount(chart.dom());
Try: Drag around an arrow to turn it · Shift-drag outward to make it longer.

Shapes as network nodes

A shape declares its box, so it can be the node mark of a network. Links meet the box's edges, and a ports channel puts connection points on them. Links treat a rotated shape as unrotated.

A supply network

Each station is a shape by kind. ports with edit.network.connect() draws new links.

const chart = Elicit({
  width: 460, height: 280,
  margins: { top: 24, right: 24, bottom: 24, left: 24 },
  axes: false,
  schema: {
    structure: "network",
    tables: {
      stations: {
        role: "nodes",
        fields: {
          id: { type: "categorical", key: true, open: true },
          kind: { type: "categorical", domain: ["source", "relay", "sink"] },
          x: { type: "quantitative", domain: [0, 100] },
          y: { type: "quantitative", domain: [0, 100] },
        },
      },
      feeds: {
        role: "links",
        directed: true,
        fields: { source: { type: "ref" }, target: { type: "ref" } },
      },
    },
  },
  data: {
    stations: [
      { id: "a", kind: "source", x: 10, y: 50 },
      { id: "b", kind: "relay", x: 40, y: 20 },
      { id: "c", kind: "relay", x: 40, y: 80 },
      { id: "d", kind: "relay", x: 68, y: 50 },
      { id: "e", kind: "sink", x: 92, y: 50 },
    ],
    feeds: [
      { source: "a", target: "b" },
      { source: "a", target: "c" },
      { source: "b", target: "d" },
    ],
  },
  marks: [
    link({ stroke: "#94A5B3", strokeWidth: 1.5, edits: [edit.network.rewire()] }),
    shape({
      size: 14,
      channels: {
        x: { field: "x", edit: move({ channels: ["x", "y"], mode: "relative" }) },
        y: { field: "y" },
        symbol: { field: "kind", scale: { range: ["triangle", "circle", "square"] } },
        fill: { field: "kind", scale: { range: ["#7DB86B", "#50AEB7", "#EE7B5E"] } },
        // Drag from a port to another station to link them.
        ports: { value: true, edit: edit.network.connect() },
      },
    }),
  ],
});
mount(chart.dom());
Try: Drag a station to move it · drag from a port to another station to link them · drag a link's end to rewire it.
