Radial axis

axisRadial() draws the theta scale as a radial axis: an arc spine, ticks, labels, and optional coloured bands for categories. orient defaults to top, running left to right through the top. channel: 'radius' draws the radius scale as concentric rings instead. The axis is inert; pair it with a needle to take an answer.

API reference

Import from elicit.elements. A curved axis for a polar scale: an arc spine with ticks and labels, and optional coloured bands behind it.

Continuous radial ticks

A quantitative theta scale gets a spine and tick marks. theta is the polar angular position, which is what a needle encodes. angle, a mark's rotation in place, has no axis.

Semi-circle axis

No needle — just the chrome. 0 on the left, 100 on the right.

const chart = Elicit({
  width: 300, height: 180,
  margins: { top: 28, right: 20, bottom: 20, left: 20 },
  axes: false,
  data: [{ n: 50 }],
  schema: { n: { type: "quantitative", domain: [0, 100] } },
  marks: [
    axisRadial({
      orient: "top", radius: 90, ticks: 6, title: "score",
      channels: { theta: { field: "n", scale: { range: [180, 0] } } },
    }),
  ],
});
mount(chart.dom());

Coloured categorical bands

A discrete domain gets one annular sector per category, coloured by an ordinal fill.

Banded likelihood arc

Seven categories across a top-facing semicircle, coloured by the reversed `dddiverging` scheme (blue→coral).

const chart = Elicit({
  width: 360, height: 210,
  margins: { top: 36, right: 64, bottom: 16, left: 64 },
  axes: false,
  overflow: "visible",   // long labels spill into the margin
  data: [{ chance: "TOSSUP" }],
  schema: {
    chance: {
      type: "ordinal",
      domain: ["VERY LIKELY D", "LIKELY D", "LEANING D", "TOSSUP",
               "LEANING R", "LIKELY R", "VERY LIKELY R"],
    },
  },
  marks: [
    axisRadial({
      orient: "top", radius: 110, bands: true, bandWidth: 28,
      labelOffset: 16, fontSize: 8,
      channels: {
        theta: { field: "chance", scale: { range: [180, 0] } },
        // RdBu is red→blue natively; reverse for the D→R (blue→red) reading.
        fill: { field: "chance", scale: { scheme: "dddiverging", reverse: true } },
      },
    }),
  ],
});
mount(chart.dom());

Tick + label customization

Ticks take the same options as Cartesian axes: ticks (a count), tickValues (explicit values), and tickFormat (a d3-format string or function). Style labels with fontSize and labelFill, and the spine with stroke.

Percent ticks at chosen values

Explicit tickValues, a percent tickFormat, and a custom label colour.

const chart = Elicit({
  width: 300, height: 190,
  margins: { top: 30, right: 24, bottom: 16, left: 24 },
  axes: false,
  overflow: "visible",
  data: [{ p: 0.5 }],
  schema: { p: { type: "quantitative", domain: [0, 1] } },
  marks: [
    axisRadial({
      orient: "top", radius: 95,
      tickValues: [0, 0.25, 0.5, 0.75, 1],
      tickFormat: ".0%",
      labelFill: "#50AEB7", fontSize: 11,
      stroke: "#B7DEE1", tickSize: 8,
      channels: { theta: { field: "p", scale: { range: [180, 0] } } },
    }),
  ],
});
mount(chart.dom());

Rings for a radius scale

axisRadial({ channel: 'radius' }) reads the radius scale instead of theta. It draws a concentric ring at each tick, labelled up the vertical. Use it to key an arc whose slices take their rim from a radius field. The rings span the scale's own extent, from the arc's innerRadius to its outerRadius, so the axis's radius option has no effect. ticks, tickValues and tickFormat work as on the angular axis.

Rings for a radius scale

axisRadial({ channel: "radius", ticks: 4 }) behind an arc with radius: { field: "n" }.

const chart = Elicit({
  width: 300, height: 280,
  margins: { top: 16, right: 16, bottom: 16, left: 16 },
  axes: false,
  data: [
    { month: "Jan", n: 30 }, { month: "Feb", n: 45 }, { month: "Mar", n: 70 },
    { month: "Apr", n: 90 }, { month: "May", n: 60 }, { month: "Jun", n: 40 },
  ],
  schema: {
    month: { type: "categorical" },
    n:     { type: "quantitative", domain: [0, 100] },
  },
  elements: [
    // Concentric rings at the radius scale's ticks, labelled up the vertical.
    axisRadial({ channel: "radius", ticks: 4, tickFormat: "d" }),
  ],
  marks: [
    arc({
      outerRadius: 110, padAngle: 1.5,
      channels: {
        theta: { value: 1 },
        radius: { field: "n" },
        fill: { field: "month" },
      },
    }),
  ],
});
mount(chart.dom());
