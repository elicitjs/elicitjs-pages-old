Bar

bar draws one rectangle per row: a categorical band on one axis, and a value on the other, drawn as length from a baseline or as a span (x1/x2, y1/y2). bar takes its orientation from the band axis; barY forces vertical, barX horizontal. For rectangles that span both axes, use rect with brushRect().

API reference

bar(options) · barY(options) · barX(options)

Import from elicit.plot. bar infers orientation from which axis is a band; barY forces vertical, barX horizontal. All three share these options.

bar({ channels, orientation, edits, id }) → Feature
barY(options) → Feature   // orientation: "vertical"
barX(options) → Feature   // orientation: "horizontal"

Band × value

The band axis places the bars. The linear axis sets their length from a baseline.

gradient: { stops, direction } fills each bar with a linear gradient over its own box. Each stop is [offset, colour], from 0 to 1. direction: 'vertical' (the default) runs from the bottom of the bar to its top; 'horizontal' runs left to right. area and rect take the same option.

A vertical bar chart

x band of categories, y linear value.

const chart = Elicit({
  width: 380, height: 240,
  margins: { top: 16, right: 16, bottom: 28, left: 34 },
  data: [
    { cat: "A", n: 30 }, { cat: "B", n: 55 },
    { cat: "C", n: 22 }, { cat: "D", n: 44 },
  ],
  schema: {
    cat: { type: "categorical", domain: ["A", "B", "C", "D"] },
    n:   { type: "quantitative", domain: [0, 60] },
  },
  marks: [
    bar({
      fill: "#50AEB7",
      channels: {
        x: { field: "cat" },
        y: { field: "n" },
      },
    }),
  ],
});
mount(chart.dom());

Horizontal bars (barX)

Put the band on y and the value on x, and the bars run horizontally. barX forces this orientation; bar infers it from the band axis.

barX — value on x

y is the category band, x the linear value drawn rightward from the baseline.

const chart = Elicit({
  width: 380, height: 240,
  margins: { top: 14, right: 16, bottom: 26, left: 60 },
  data: [
    { region: "North", sales: 42 }, { region: "South", sales: 68 },
    { region: "East", sales: 30 },  { region: "West", sales: 54 },
  ],
  schema: {
    region: { type: "categorical", domain: ["North", "South", "East", "West"] },
    sales:  { type: "quantitative", domain: [0, 80] },
  },
  marks: [
    barX({
      fill: "#1B3F60",
      channels: {
        y: { field: "region" },
        x: { field: "sales" },
      },
    }),
  ],
});
mount(chart.dom());

Stacked bars

stack: true stacks the bars that share a band. Each segment sits on the cumulative total of the ones before it. Rows with the same x (or y, for barX) stack together. Declare a schema domain that covers the stacked total.

Segments are ordered by the mark's series field, so the same category sits at the same height in every band. The series channel sets which rows form a series; without it, the field on fill (then stroke) does. Span mode takes precedence over stack: give the value axis x1/x2 or y1/y2 and the bars draw as spans.

A stacked bar chart

stack: true with fill: { field: "asset" }. The pct domain covers the total, [0, 100].

const chart = Elicit({
  width: 380, height: 240,
  margins: { top: 16, right: 16, bottom: 28, left: 40 },
  data: [
    { year: "2023", asset: "stocks", pct: 50 },
    { year: "2023", asset: "bonds",  pct: 30 },
    { year: "2023", asset: "cash",   pct: 20 },
    { year: "2024", asset: "stocks", pct: 65 },
    { year: "2024", asset: "bonds",  pct: 20 },
    { year: "2024", asset: "cash",   pct: 15 },
  ],
  schema: {
    year:  { type: "categorical", domain: ["2023", "2024"] },
    asset: { type: "categorical", domain: ["stocks", "bonds", "cash"] },
    pct:   { type: "quantitative", domain: [0, 100] },
  },
  legends: true,
  marks: [
    bar({
      stack: true,
      channels: {
        x:    { field: "year" },
        y:    { field: "pct" },
        fill: { field: "asset" },
      },
    }),
  ],
});
mount(chart.dom());

Grouped bars (xOffset, yOffset)

xOffset splits each x category into one sub-band per value of a second field, so the bars of one category sit side by side. yOffset does the same inside each y category, for grouped barX. The offset needs a categorical x (or y) to divide. It has no axis, so colour the groups with fill on the same field and turn on its legend.

Sub-bands touch by default, and the gap between categories is the x band's padding. scale: { padding } on the offset channel opens a gap inside each group. yOffset puts its first value at the bottom of the slot, as a band y axis does.

A bar draws only for a row that names both a category and a group. Combine xOffset with stack: true and each sub-band stacks on its own. create() and toggle() read the group from where you click, and move({ channels: ["x", "xOffset"] }) drags a bar into another category and group.

Grouped bars

xOffset: { field: "year" } splits each region into three sub-bands. y carries edit: move().

const chart = Elicit({
  width: 400, height: 250,
  margins: { top: 16, right: 16, bottom: 28, left: 36 },
  data: [
    { region: "North", year: "2022", sales: 40 }, { region: "North", year: "2023", sales: 55 },
    { region: "North", year: "2024", sales: 62 }, { region: "South", year: "2022", sales: 30 },
    { region: "South", year: "2023", sales: 34 }, { region: "South", year: "2024", sales: 48 },
    { region: "West",  year: "2022", sales: 52 }, { region: "West",  year: "2023", sales: 47 },
    { region: "West",  year: "2024", sales: 58 },
  ],
  schema: {
    region: { type: "categorical", domain: ["North", "South", "West"] },
    year:   { type: "categorical", domain: ["2022", "2023", "2024"] },
    sales:  { type: "quantitative", domain: [0, 80] },
  },
  marks: [
    barY({
      channels: {
        x:       { field: "region" },
        xOffset: { field: "year" },
        y:       { field: "sales", edit: move() },

});

Fill in one group

context marks 2023 as given; you drag the 2024 bar beside it in each region.

// 2023 is given; you estimate 2024 beside it in every region.
const regions = ["North", "South", "West", "East"];
const given = { North: 55, South: 34, West: 47, East: 40 };
const chart = Elicit({
  width: 400, height: 250,
  margins: { top: 16, right: 16, bottom: 28, left: 36 },
  data: regions.flatMap((region) => [
    { region, year: "2023", sales: given[region] },
    { region, year: "2024", sales: given[region] },
  ]),
  context: (d) => d.year === "2023",
  schema: {
    region: { type: "categorical", domain: regions },
    year:   { type: "categorical", domain: ["2023", "2024"] },
    sales:  { type: "quantitative", domain: [0, 80] },
  },
  constraints: [clamp({ min: 0 })],
  marks: [
    barY({
      channels: {
        x:       { field: "region" },
        xOffset: { field: "year", scale: { padding: 0.1 } },
        y:       { field: "sales", edit: move() },
        fill:    { field: "year", scale: { range: ["#BCC9D4", "#50AEB7"] },
                   legend: { anchor: "top", title: false } },
      },
    }),
  ],
});
mount(chart.dom());

Slicing a stack

A stacked bar divides one total among its rows. Three gestures reshape it, the same three that work on a pie or donut:

  • edit.stack.cut() — click inside a segment to divide it in two at that point.
  • edit.stack.edge() — drag a boundary to move value across it. Only the two segments it separates change.
  • edit.stack.merge() — double-click a boundary to fuse those two back into one.

All three preserve the band's total. Cutting divides a magnitude, dragging moves value from one row to its neighbour, and merging adds two into one. Boundary handles appear once one of these edits is set, and take the shared handles / handleSize / handleColor options.

A cut mints a row and takes its category from the schema's domain, so building a stack takes no typing. A closed domain (the default) hands out the values that band doesn't yet use, and refuses the cut once they run out. Each band draws from its own copy of the domain, so bonds in 2023 and bonds in 2024 are both available.

Set open: true on the field's schema entry and the domain becomes a starting set instead: a cut appends a new category to it, named from label ("Category" by default) for you to rename later with edit.scale.categories(). An open field also skips the out-of-domain check on seed data.

Cut a stack into parts

Each year starts as one 100% block. The asset domain declares four categories, so each band takes four cuts.

const chart = Elicit({
  width: 380, height: 260,
  margins: { top: 16, right: 16, bottom: 28, left: 40 },
  data: [
    { year: "2023", asset: "stocks", pct: 100 },
    { year: "2024", asset: "stocks", pct: 100 },
  ],
  schema: {
    year:  { type: "categorical", domain: ["2023", "2024"] },
    asset: { type: "categorical", domain: ["stocks", "bonds", "cash", "gold"] },
    pct:   { type: "quantitative", domain: [0, 100] },
  },
  legends: true,
  marks: [
    bar({
      stack: true,
      channels: {
        x:    { field: "year" },
        y:    { field: "pct" },
        fill: { field: "asset" },
      },
      edits: [
        edit.stack.cut(),
        edit.stack.edge(),
        edit.stack.merge(),
      ],
    }),
  ],
});
mount(chart.dom());

Explicit spans (x1/x2, y1/y2)

Give the value axis two endpoints, x1/x2 for barX or y1/y2 for barY, and each bar spans from one to the other instead of starting at the baseline. Use it for a range per category, as in a Gantt chart. x1/x2 share the scale of x (likewise y1/y2 with y), so only one needs an explicit type and domain.

Years active per person

barX with x1/x2 spans; y is the category band.

const chart = Elicit({
  width: 380, height: 220,
  margins: { top: 14, right: 16, bottom: 26, left: 60 },
  data: [
    { person: "Ada",   start: 1830, end: 1852 },
    { person: "Grace", start: 1930, end: 1992 },
    { person: "Alan",  start: 1931, end: 1954 },
  ],
  schema: {
    person: { type: "categorical", domain: ["Ada", "Grace", "Alan"] },
    start:  { type: "quantitative", domain: [1820, 2000] },
    end:    { type: "quantitative", domain: [1840, 2000] },
  },
  marks: [
    barX({
      fill: "#8A78C0",
      channels: {
        y: { field: "person" },
        x1: { field: "start" },
        x2: { field: "end" },
      },
    }),
  ],
});
mount(chart.dom());

Brush: edges + body together

brushSpan() combines both: grab near an edge to resize just that end, grab the body to move the whole span. Drag an edge past the other and release — the fields re-sort (start stays ≤ end) with no visual jump.

const chart = Elicit({
  width: 380, height: 220,
  margins: { top: 14, right: 16, bottom: 26, left: 60 },
  data: [
    { person: "Ada",   start: 1830, end: 1852 },
    { person: "Grace", start: 1930, end: 1992 },
    { person: "Alan",  start: 1931, end: 1954 },
  ],
  schema: {
    person: { type: "categorical", domain: ["Ada", "Grace", "Alan"] },
    start:  { type: "quantitative", domain: [1820, 2000] },
    end:    { type: "quantitative", domain: [1840, 2000] },
  },
  marks: [
    barX({
      fill: "#50AEB7",
      channels: {
        y: { field: "person" },
        x1: { field: "start" },
        x2: { field: "end" },
      },
      edits: [
        brushSpan({ channels: ["x1", "x2"], threshold: 40,
                    edgeInset: 10, guide: true }),
      ],
    }),
  ],
});
mount(chart.dom());
Try: Drag an edge to resize it, the body to move the whole bar, or drag one edge past the other to see it flip.

Editing bars

Put edit: move() on the value channel and drag a bar to rewrite its value. With pick: "nearest", you grab a bar from anywhere in its column, which helps with thin bars. A bar dragged to the baseline collapses to zero length but keeps a minimum grab target, with either pick mode, so you can drag it back up.

Drag a value

y carries edit: move(). Dragging writes y back through the same scale.
