Renderers

A mark produces plain-data scene nodes: a circle at cx,cy, a rect, a path. The engine hands the whole scene to a renderer, which draws the nodes and reports gestures back. The renderer is the only link between the engine and the screen, so marks, edits, scales, guides and constraints behave the same under any renderer. Set it with renderer: on the spec.

The default is new D3Renderer(), an SVG backend. new CanvasRenderer() implements the same contract (render(context) in, onEvent out) and draws to a <canvas>. The examples below run on canvas, and every edit behaves as it does under SVG, because the interaction model lives in the engine. Two effect props, filter and cursor, apply only under SVG. The default grabbed effect is a filter, so canvas shows no grab feedback unless you give grabbed an opacity or an outline.

Direct-pick drag, on canvas

Under SVG, the browser picks the element under the pointer. A canvas is a single element, so the canvas renderer finds the touched mark geometrically, with the same distance maths as the nearest pick. It then dispatches the same move edit. Drag a bar and the gesture inverts through the y scale and rewrites the value, as it does under SVG.

Drag a value (canvas)

renderer: new CanvasRenderer(). y carries edit: move(); the direct-pick target is hit-tested geometrically against the scene nodes.

const chart = Elicit({
  width: 380, height: 260,
  renderer: new CanvasRenderer(),
  margins: { top: 14, right: 14, bottom: 26, left: 30 },
  data: [
    { x: "A", y: 20 }, { x: "B", y: 45 },
    { x: "C", y: 30 }, { x: "D", y: 60 },
  ],
  schema: {
    x: { type: "categorical", domain: ["A", "B", "C", "D"] },
    y: { type: "quantitative", domain: [0, 100] },
  },
  marks: [
    bar({
      fill: "#50AEB7",
      channels: {
        x: { field: "x" },
        y: { field: "y", edit: move() },
      },
    }),
  ],
});
mount(chart.dom());
Try: Drag a bar up or down.

Plane gestures, on canvas

Plane-driven edits (sweep, draw, nearest, create) resolve their target from the pointer coordinates. The canvas renderer feeds those coordinates through the same pointer state machine, so a you-draw-it sweep works unchanged.

Sweep a line (canvas)

A plane-pick sweep: drag across the plot to redraw the line. It works from pointer coordinates through the scale, with no node identity needed.

const chart = Elicit({
  width: 420, height: 260,
  renderer: new CanvasRenderer(),
  margins: { top: 16, right: 16, bottom: 40, left: 44 },
  data: [
    { month: 0, demand: 50 }, { month: 1, demand: 50 },
    { month: 2, demand: 50 }, { month: 3, demand: 50 },
    { month: 4, demand: 50 }, { month: 5, demand: 50 },
  ],
  schema: {
    month:  { type: "quantitative", domain: [0, 5] },
    demand: { type: "quantitative", domain: [0, 100] },
  },
  axes: { x: { title: "Month" }, y: { title: "Demand" } },
  marks: [
    lineY({
      stroke: "#315228", strokeWidth: 3, curve: "catmullRom",
      channels: {
        x: { field: "month" },
        y: { field: "demand", edit: move({ pick: "sweep", guide: true }) },
      },
    }),
  ],
});
mount(chart.dom());
Try: Drag left-to-right across the chart to reshape the line.
