Mark & element contracts

What every factory is for: its kind, whether create and remove apply, and what you grab. Axes, grids and legends are on elements.*.

Kinds of factory

KindMeaning
dataViews dataset rows; channels name columns
parametricChannels are curve parameters (trend); rows are not created freely
map chromeBasemap / tiles; pointer-transparent
elementViews a scale; its edits write the domain, not rows

Data, parametric and map-chrome factories are all marks: they view rows. An element views a scale. Guides, the third kind on Core concepts, view state and are covered on Guides.

Marks are inert until an edit names the column it writes. Edits write fields, so an edit goes on a { field } channel. A constant { value } channel carries none.

Guides and effects

An edit's guide: option draws its rules: bounds, catchment and track. An effect shows interaction state: hovered, selected or grabbed. Edits that select a target (pick: "nearest", pick: "sweep", brushSpan, brushRect, edit.geo.brush) turn catchment on when you omit guide. Set guide: false to turn it off. See Guides and Effects.
