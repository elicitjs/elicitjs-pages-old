Theming & style

Every default colour, font, and affordance token lives in one place — the theme. Pass a partial theme on Elicit (or on any widget) and it deep-merges over the built-in defaults, so you name only what you change. It sits alongside, and under, the two style hooks you already have: a per-datum paint channel (fill, stroke) still wins over any theme token, and the effects layer still owns interaction feedback. Eighteen named themes ship with the library — theme: "nyt" restyles a whole chart from one word.

API reference

theme (on Elicit)

The style layer, passed as theme on Elicit (or on any widget). A partial, deep-merged over the built-in DEFAULT_THEME — you name only the tokens you change. Precedence, most specific first: a per-datum channel/option > theme.marks[name] > the theme token > the renderer default.

theme: { extends, ink, accent, muted, handle, handleStroke, background, palette, ramp, diverging,
         font, title, subtitle, caption, axis, grid, panel, bandPadding, guide, constraint,
         effects, ghost, widget, marks }
theme: "nyt"   // a named theme — see /theming/themes

themes

The eighteen named themes: default, survey, dark and dd, plus fourteen house styles from Flint. Each is a partial — pass it (or its name) as theme, or start from one with extends.

themes.default · survey · dark
themes.nyt · economist · bbc · datawrapper
themes.swiss · nature · deStijl
themes.mckinsey · powerbi · powerbiLight
themes.apple · material · pop · cartoon

setTheme(partial)

Set the application-wide default theme. Every chart created afterwards inherits it unless it passes its own theme, which layers on top. Pass null to reset.

setTheme(themes.survey)
setTheme('economist')
setTheme({ ink: '#4f46e5' })
setTheme(null)

A themed instrument

themes.survey is a built-in professional look. Pass it to any widget and the answer ink, the chrome, and the affordance rings/track/labels all follow it — the behaviour is unchanged, only the style.

The survey theme

One object — themes.survey — restyles ink, chrome, and every affordance.

// One object restyles the whole instrument: answer ink, chrome, and the
// affordance rings/track/labels all follow themes.survey.
mount(Elicit(widgets.likert({
  question: "How satisfied are you with the result?",
  options: ["Very low", "Low", "Neutral", "High", "Very high"],
  theme: themes.survey,
})));
Try: move across the options, click to answer — the look is the only change.

Dark mode

Yes — a theme can produce a fully dark chart. The background token paints the chart's own surface (svg / canvas, margin band included), so themes.dark is self-contained: light ink, light labels, a slate grid, no host CSS required. The same spec renders light or dark; only the theme changes.

themes.dark

A slate backdrop with light ink and chrome — the chart paints its own surface.

// themes.dark carries a `background` token, so the chart paints its own dark
// surface — light ink, light labels, slate grid, no host CSS required. The same
// spec renders identically light or dark; only the theme changes.
mount(Elicit({
  width: 440, height: 240,
  margins: { top: 20, right: 20, bottom: 30, left: 36 },
  data: [{ cat: "A", n: 30 }, { cat: "B", n: 55 }, { cat: "C", n: 40 }, { cat: "D", n: 22 }],
  schema: {
    cat: { type: "categorical", domain: ["A", "B", "C", "D"] },
    n: { type: "quantitative", domain: [0, 60] },
  },
  theme: themes.dark,
  axes: { x: {}, y: { grid: true } },
  marks: [
    barY({ channels: { x: { field: "cat" }, y: { field: "n", edit: move() } } }),
  ],
}));
Try: drag a bar — the interaction is identical, only the palette is dark.

A theme on a plain chart

A theme is plain data — no functions, no classes — so it merges cleanly. ink is the primary mark colour (every mark with no explicit paint channel reads it); axis and grid are the chrome. Name a token and it changes; leave one out and it inherits the default.

Per-chart theme

ink recolours the bars; axis/grid restyle the chrome. Drag a bar — the value axis still works.

// A theme on a plain chart. `ink` recolours every mark that has no explicit
// paint channel; `axis`/`grid` restyle the chrome. A partial — you name only
// the tokens you change, the rest inherit the default.
mount(Elicit({
  width: 440, height: 240,
  margins: { top: 20, right: 20, bottom: 30, left: 36 },
  data: [{ cat: "A", n: 30 }, { cat: "B", n: 55 }, { cat: "C", n: 40 }, { cat: "D", n: 22 }],
  schema: {
    cat: { type: "categorical", domain: ["A", "B", "C", "D"] },
    n: { type: "quantitative", domain: [0, 60] },
  },
  theme: {
    ink: "#EE7B5E",
    axis: { stroke: "#BCC9D4", labelFill: "#6F8294" },
    grid: { stroke: "#EDF7F8" },
  },
  axes: { x: {}, y: { grid: true } },
  marks: [
    barY({ channels: { x: { field: "cat" }, y: { field: "n", edit: move() } } }),
  ],
}));
Try: drag a bar up or down.

Axes, grids and the plot panel

The axis tokens style every axis: stroke and strokeWidth for the spine and ticks, line: false to drop the spine, tickSize (0 for none) and tickPadding for the gap to the label, labelAngle to turn the labels. Each is also an axis() option, which wins. grid.show adds gridlines you did not ask for. panel paints the plot area under the grid and can frame it; background covers the margins too. bandPadding sets the gap between bars.

axis.discrete and axis.continuous override any axis token for axes of that kind. That is how a house drops the spine on the value axis and keeps it under the categories. grid.show: "value" grids the axis the value runs along: the continuous one, or y when both are. grid.zero draws an emphasised line at 0.

A grey panel, white gridlines

panel, grid, axis and bandPadding tokens, and nothing else.

// The ggplot2 look from tokens alone: a grey panel under white gridlines,
// no spines or ticks, and wider gaps between the bars.
mount(Elicit({
  width: 440, height: 260,
  theme: {
    panel: { fill: "#EAF0F4" },
    grid: { stroke: "#ffffff", strokeWidth: 1.2, show: "all" },
    axis: { line: false, tickSize: 3, stroke: "#14283A", labelFill: "#46596B" },
    bandPadding: 0.35,
    ink: "#46596B",
  },
  data: [{ cat: "A", n: 30 }, { cat: "B", n: 55 }, { cat: "C", n: 40 }, { cat: "D", n: 22 }],
  schema: {
    cat: { type: "categorical", domain: ["A", "B", "C", "D"] },
    n: { type: "quantitative", domain: [0, 60] },
  },
  axes: { y: { title: "count" } },
  marks: [barY({ channels: { x: { field: "cat" }, y: { field: "n", edit: move() } } })],
}));
Try: drag a bar.

Per-kind axes and a zero rule

A spine under the categories, none on the values, a dotted value grid and a rule at 0.

// `axis.discrete` / `axis.continuous` style each KIND of axis apart: a spine
// under the categories, none on the values, a dotted value grid and a rule at 0.
mount(Elicit({
  width: 440, height: 260,
  theme: {
    axis: {
      tickSize: 0, tickPadding: 6,
      discrete: { line: true, stroke: "#20555A" },
      continuous: { line: false },
    },
    grid: { show: "value", strokeDash: "1 3", stroke: "#94A5B3", zero: { stroke: "#20555A", strokeWidth: 1.5 } },
  },
  data: [{ q: "Q1", d: 12 }, { q: "Q2", d: -8 }, { q: "Q3", d: 20 }, { q: "Q4", d: 5 }],
  schema: {
    q: { type: "categorical", domain: ["Q1", "Q2", "Q3", "Q4"] },
    d: { type: "quantitative", domain: [-20, 30] },
  },
  marks: [barY({ channels: { x: { field: "q" }, y: { field: "d", edit: move() } } })],
}));
Try: drag Q2 above zero.

Typography

font.family sets the chart's typeface; null inherits the page's. title, subtitle and caption each take fontFamily, fontStyle, fontWeight, fontSize and fill, so a headline can be a serif over sans-serif labels. The axis takes fontFamily and fontWeight for its labels and titleFill, titleFontSize and titleFontWeight for its title. A text mark takes fontWeight, fontStyle and fontFamily, each a constant or a channel.

A serif title over sans-serif labels

font, title, subtitle and axis tokens, and a bold text mark.

// Type from the theme: a body family, a serif title, bold axis titles. A text
// mark takes `fontWeight`, `fontStyle` and `fontFamily` per label.
mount(Elicit({
  width: 440, height: 280,
  title: "How sure are you?",
  subtitle: "Drag each bar to your confidence",
  theme: {
    font: { family: "'Helvetica Neue', Helvetica, Arial, sans-serif" },
    title: { fontFamily: "Georgia, serif", fontSize: 20 },
    subtitle: { fontStyle: "italic" },
    axis: { titleFontWeight: "bold", titleFill: "#20555A" },
  },
  axes: { x: false, y: { title: "Confidence (%)" } },
  data: [{ claim: "Claim 1", c: 70 }, { claim: "Claim 2", c: 35 }, { claim: "Claim 3", c: 55 }],
  schema: {
    claim: { type: "categorical", domain: ["Claim 1", "Claim 2", "Claim 3"] },
    c: { type: "quantitative", domain: [0, 100] },
  },
  marks: [
    barY({ rx: 3, channels: { x: { field: "claim" }, y: { field: "c", edit: move() } } }),
    text({
      dy: -10, fontWeight: "bold", fill: "white",
      channels: { x: { field: "claim" }, y: { datum: 0 }, text: { field: "claim" } },
    }),
  ],
}));
Try: drag a bar.

Titles and captions

title, subtitle and caption on the Elicit spec draw text above and below the plot, left-aligned with it. They reserve layout space the way a legend does: the chart keeps its declared width and height, and the plot shrinks to make room. The theme's title, subtitle and caption tokens style them, each { fill, fontSize, fontWeight }. A token with no fill takes the axis label colour, so the titles follow a dark theme.

A titled chart with a caption

title, subtitle and caption on the spec; theme.title and theme.caption recolour two of them.

mount(Elicit({
  width: 440, height: 260,
  margins: { top: 12, right: 40, bottom: 12, left: 56 },
  title: "How will the vote split?",
  subtitle: "Drag each bar to your estimate",
  caption: "Shares in percent; they need not sum to 100.",
  // Title tokens restyle all three; omitted ones keep their defaults.
  theme: { title: { fill: "#50AEB7" }, caption: { fill: "#6F8294" } },
  axes: { x: false },
  data: [{ party: "Left", n: 38 }, { party: "Centre", n: 24 }, { party: "Right", n: 33 }],
  schema: {
    party: { type: "categorical", domain: ["Left", "Centre", "Right"] },
    n:     { type: "quantitative", domain: [0, 60] },
  },
  marks: [
    barX({
      fill: "#50AEB7",
      channels: {
        y: { field: "party", scale: { reverse: true } },
        x: { field: "n", edit: move() },
      },
    }),
    text({
      dx: 6, textAnchor: "start", fontSize: 12, format: ".0f",
      channels: { y: { field: "party" }, x: { field: "n" }, text: { field: "n" } },
    }),
  ],
}));
Try: drag a bar — the plot sits between the title block and the caption.

Overrides & precedence

Resolution is layered, most specific first: a per-datum channel or option beats theme.marks[name], which beats the theme token (ink), which beats the renderer default. So a theme sets the family look while a single mark can still opt out.

Per-mark override

ink colours the bars; theme.marks.point overrides just the dots.

// Precedence, most specific first: a per-datum channel > theme.marks[name] >
// the theme token > the renderer default. Here `ink` colours the bars, but
// theme.marks.point overrides just the dots — and a channel would still win.
mount(Elicit({
  width: 440, height: 240,
  margins: { top: 20, right: 20, bottom: 30, left: 36 },
  data: [{ cat: "A", n: 30 }, { cat: "B", n: 55 }, { cat: "C", n: 40 }, { cat: "D", n: 22 }],
  schema: {
    cat: { type: "categorical", domain: ["A", "B", "C", "D"] },
    n: { type: "quantitative", domain: [0, 60] },
  },
  theme: {
    ink: "#2B5D87",
    marks: { point: { fill: "#F2B94B" } },
  },
  marks: [
    barY({ channels: { x: { field: "cat" }, y: { field: "n" } } }),
    point({
      size: 6,
      channels: { x: { field: "cat" }, y: { field: "n", edit: move() } },
    }),
  ],
}));
Try: drag a dot — its colour comes from theme.marks.point, not ink.

App-wide defaults

To theme a whole application without threading theme through every chart, call setTheme(partial) once at startup — every chart built afterwards inherits it, and a chart's own theme still layers on top. setTheme(themes.survey) makes the survey look the default; setTheme(null) resets to the built-in.

import { setTheme, themes } from "elicit-js";

setTheme(themes.survey);          // app-wide default
// …every Elicit(...) after this inherits it
setTheme("economist");            // or a named theme by name
setTheme({ ink: "#4f46e5" });     // or just a token or two
