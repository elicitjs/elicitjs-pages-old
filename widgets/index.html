Widgets

Widgets are ready-made elicitation interfaces for survey questions. Each one returns an ElicitSpec built from ordinary marks, edits and constraints, with option rings, cell grids and tracks drawn as guides. Render one with Elicit(widgets.likert({…})). The Likert scale below appears both as a widget and as the plain-API spec it expands to.

API reference

widgets.likert · multipleChoice · slider · matrix · lineCone · ranking · allocation · …

Import from elicit.widgets. Each returns an ElicitSpec; pass it straight to Elicit. The chart draws one dataset, so getData() reads the answer.

multipleChoice({ question, options, max, value, onChange }) → ElicitSpec
slider({ question, domain, step, value, format, onChange }) → ElicitSpec
thermometer({ question, domain, step, value, onChange }) → ElicitSpec
matrix({ question, questions, options, value, onChange }) → ElicitSpec
ranking({ question, items, onChange }) → ElicitSpec
allocation({ question, categories, total, values, onChange }) → ElicitSpec

Returns / emits

An ElicitSpec — an ordinary spec, so you can read it, change one key, and pass it on. The chrome each widget draws itself with is a guide: guides.prompt, guides.optionRings, guides.cellGrid, guides.sliderTrack, guides.quadrants. The plain-API twins below use those same guides, so each block stands alone.

Likert scale — widget & plain API

A point on a band of options, a create({ pick: "probe" }) edit, and count({ max: 1, strategy: "replace" }). Hover to preview the answer, and click to set it. The plain-API version uses the same mark, edit and constraint, and draws the same look with inline guides.custom helpers.

As a widget

Rings, track and labels come from the guide layer.

const chart = Elicit(widgets.likert({
  question: "This tool is easy to use",
  options: ["Strongly disagree","Disagree","Neutral","Agree","Strongly agree"],
}));
mount(chart.dom());
Try: hover across the scale, then click.

The same thing, plain API

Same mark, edit, and constraint — rings/prompt defined inline as guides. This is what widgets.likert expands to.

const options = ["Strongly disagree","Disagree","Neutral","Agree","Strongly agree"];
const radius = 11;

const prompt = (text) => guides.custom(() => [{
  type: "text", x: 0, y: -18, text,
  textAnchor: "start", fontSize: 13, fill: "#20555A",
}]);

const optionRings = () => guides.custom((ctx) => {
  const cats = ctx.scales.x.domainConfig || [];
  const cy = ctx.height / 2;
  const cxOf = (c) => ctx.scales.x.encode(c);
  const nodes = [];
  for (let i = 0; i < cats.length - 1; i++) {
    nodes.push({
      type: "line",
      x1: cxOf(cats[i]) + radius, y1: cy,
      x2: cxOf(cats[i + 1]) - radius, y2: cy,
      stroke: "#D9E2E9", strokeWidth: 3, background: true,
    });
  }
  for (const c of cats) {
    nodes.push({
      type: "circle", cx: cxOf(c), cy, r: radius,
      fill: "none", stroke: "#BCC9D4", strokeWidth: 1.5,
    });
    nodes.push({
      type: "text", x: cxOf(c), y: cy + 30, text: String(c),
      textAnchor: "middle", fontSize: 12, fill: "#20555A",
    });
  }
  return nodes;
});

const chart = Elicit({
  width: 560, height: 130,
  margins: { top: 34, right: 60, bottom: 44, left: 60 },
  axes: false,
  data: [],
  schema: { choice: { type: "ordinal", domain: options } },
  scales: { x: { type: "band" } },
  constraints: [ count({ max: 1, strategy: "replace" }) ],
  guides: [ prompt("This tool is easy to use"), optionRings() ],
  marks: [
    point({
      id: "likert",
      size: radius - 3,
      fill: "#50AEB7",
      channels: { x: { field: "choice" } },
      edits: [ create({ pick: "probe", channels: ["x"], advance: false }) ],
    }),
  ],
});
mount(chart.dom());
Try: same look, same interaction — change any line to customize.

Multiple choice

toggle() combines create and remove in one gesture. Click an empty option to pick it, and click your pick to take it back. count() caps the number of picks.

Multiple choice (pick ≤ 2)

The hover shows whether a click will pick or un-pick.

const chart = Elicit(widgets.multipleChoice({
  question: "Which apply?",
  options: ["Fast","Cheap","Reliable","Simple"],
  max: 2,
}));
mount(chart.dom());
Try: pick two, then click one again.

Slider

A single knob that follows the pointer and settles when you click or release a drag: move({ pick: "probe" }). snap() lands it on steps.

Slider

Track, end caps and value labels are guides.

const chart = Elicit(widgets.slider({
  question: "How likely is it? (%)",
  domain: [0, 100], step: 5, value: 40,
}));
mount(chart.dom());
Try: move across the track and click — or grab the knob and drag.

Question matrix

Questions on a band y, options on a band x. toggle() on (x, y) picks a cell, and unique({ field: "question", strategy: "replace" }) keeps one answer per row.

Question matrix

The cell grid is a guide, so it never swallows the click.

const chart = Elicit(widgets.matrix({
  question: "Rate each aspect",
  questions: ["Speed","Cost","Support"],
  options: ["Poor","OK","Good","Great"],
}));
mount(chart.dom());
Try: answer each row; click a row again elsewhere to change it.

Line + Cone

A two-step correlation question. Aim the line and click, then open the cone and click. getData() returns [{ r, spread }], and on("stage") reports which question you are on (2 = both answered).

It is a preset over trendBand and trend on one dataset. A pinned intercept: { datum: 0 } channel and two clamp constraints state the correlation. The trend page has the same spec written out. The inner plot is square, so the line’s screen angle reads as r.

Line + Cone

Crosshair frame and high/low variable labels are guides.

const chart = Elicit(widgets.lineCone({
  question: "What is the relationship?",
  x: "Exercise amount", y: "Body weight",
}));
mount(chart.dom());
const out = document.createElement("div");
out.style.cssText = "font:12px ui-monospace,monospace;color:#6F8294";
const show = () => {
  const d = chart.getData()[0];
  out.textContent = "stage " + chart.getStage() +
    "  ·  r=" + d.r.toFixed(2) + "  spread=" + d.spread.toFixed(2);
};
chart.on("change", show); chart.on("stage", show); show();
mount(out);
Try: move, click, move, click.

Customizing styles

Every widget accepts a theme, which restyles the answer ink, chrome and affordances together. See Theming. For a one-off change, edit the plain-API version: repaint the answer mark or swap a guide. The edits and constraints stay the same.

Restyle with a theme

widgets.slider({ …, theme: themes.survey }) — one object restyles the instrument.

// The same slider, restyled by themes.survey — answer ink, track, and labels
// all follow the theme. See /theming.
const chart = Elicit(widgets.slider({
  question: "How confident are you?",
  domain: [0, 100],
  value: 60,
  theme: themes.survey,
}));
mount(chart.dom());
Try: drag the knob — only the look changed.

More instruments

Ranking, allocation, tokens, intervals, histograms, regions, thermometers and labelled values. Each accepts question, onChange, stage and theme. Starting answers use options specific to each widget, such as value, values, bins or mean / lo / hi.

interval is three move() handles over one row, coupled by constraints. follow carries the caps with the mean, ordering keeps lo ≤ mean ≤ hi, and clamp holds all three inside domain. symmetric: true adds symmetric, so dragging one cap mirrors the other about the mean.

Ranking

Drag items to reorder. It expands to a rank edit.

const chart = Elicit(widgets.ranking({
  question: "Rank these priorities",
  items: ["Cost", "Speed", "Quality", "Risk"],
}));
mount(chart.dom());
Try: Drag a dot up or down to swap ranks.

Allocation

Bars that redistribute to keep a fixed sum.

const chart = Elicit(widgets.allocation({
  question: "Allocate 100 points",
  categories: ["A", "B", "C", "D"],
  total: 100,
}));
mount(chart.dom());
Try: Drag a bar — siblings rebalance to 100.

Region

rect + brushRect for a 2-D region.

const chart = Elicit(widgets.region({
  question: "Where do you expect the outcome?",
}));
mount(chart.dom());
Try: Drag edges, corners, or the body.

Interval / CI

Drag the mean to translate the whole interval; drag a cap to resize one end.

const chart = Elicit(widgets.interval({
  question: "Your estimate and range",
  mean: 50, lo: 30, hi: 70,
}));
mount(chart.dom());
Try: Drag the centre — lo/hi follow. Drag a cap — mean stays put.

Symmetric interval

widgets.interval({ symmetric: true }) — one cap mirrors the other.

const chart = Elicit(widgets.interval({
  question: "Your estimate, ± the same either way",
  mean: 50, lo: 35, hi: 65,
  symmetric: true,
}));
mount(chart.dom());
Try: Drag a cap — the other moves the same distance the opposite way. Drag the centre — the interval follows.

Thermometer

A single value as a vertical bar — probe drag, snap to step.

const chart = Elicit(widgets.thermometer({
  question: "How likely is rain tomorrow?",
  domain: [0, 100],
  step: 5,
  value: 40,
}));
mount(chart.dom());
Try: Drag the bar (or move & click) — it snaps to the step.

Histogram

Editable frequency bins — drag each bar to its count.

const chart = Elicit(widgets.histogram({
  question: "How many cups of coffee per day?",
  bins: ["0", "1", "2", "3", "4+"],
  max: 40,
}));
mount(chart.dom());
Try: Drag a bar up or down to set its count.

Probability tokens

Discrete mass as stacked tokens — probe-create a ghost token, click to drop; alt-click removes.

const chart = Elicit(widgets.probabilityTokens({
  question: "Spread 20 tokens over the outcomes you expect",
  bins: ["Low", "Med", "High"],
  maxTokens: 20,
}));
mount(chart.dom());
Try: Hover a bin and click to drop a token · Alt-click to remove.
