Stages

Stages split a question into steps: first do X, then do Y. Give an edit a numeric stage and it is active only in that stage; an edit with no stage is always active. Stages work with every mark and edit. Move between them with nextStage(), setStage(n) and getStage(), and listen with on("stage", cb).

API reference

edit({ stage }) · container.setStage / nextStage / getStage

Add stage to any edit factory. The engine filters edits by the current stage in dispatch, cursor, plane-on-top, and guides — one gate everywhere.

move({ stage: 1 })            // active only in stage 1
const chart = Elicit({ stage: 0, ... });
chart.getStage() → number
chart.setStage(n)            // set, emit "stage", re-render
chart.nextStage()            // setStage(current + 1)
chart.on("stage", (n) => …)  // subscribe; returns an unsubscribe fn
Options
OptionType · defaultDescription
edit.stage
numberdefaultnull
The stage this edit is active in. Unset, it is active in every stage.
spec.stage
numberdefault0
Which stage the chart starts on.
spec.stageLabels
string[]default[]
A caption per stage, read back with getStageLabel().
edit.advance
booleandefaulttrue
Whether a settled probe click moves the chart on. Set false to answer repeatedly within one stage.
Returns / emits

setStage and nextStage emit stage and re-render. The stage gates dispatch, the cursor, plane pick order, and guides, so an edit outside the current stage is inert everywhere at once.

Place, then size

Stage 0 drags the point along x (where). Stage 1 resizes it (how confident). Only one edit is live at a time.

A staged probe edit advances the stage when it commits. Set advance: false on it to advance by hand instead.

Two-stage point

Same mark, two staged edits, a Next button.

const chart = Elicit({
  width: 380, height: 240,
  margins: { top: 16, right: 16, bottom: 28, left: 16 },
  axes: { x: {}, y: false },
  stage: 0,
  data: [{ x: 5, mag: 12 }],
  onChange: (d) => console.log(d[0]),
  schema: {
    x:   { type: "quantitative", domain: [0, 10] },
    mag: { type: "quantitative", domain: [0, 14] },
  },
  marks: [
    point({
      channels: {
        x: { field: "x", edit: move({ stage: 0 }) },
        size: { field: "mag", edit: resize({ stage: 1 }) },
      },
    }),
  ],
});
mount(chart.dom());
const label = document.createElement("div");
const render = () => { label.textContent = "stage: " + chart.getStage(); };
chart.on("stage", render); render();
const btn = document.createElement("button");
btn.textContent = "Next";
btn.onclick = () => chart.nextStage();
const controls = document.createElement("div");
controls.style.cssText = "margin-top:8px;display:flex;gap:10px;align-items:center";
controls.append(btn, label);
mount(controls);
Try: drag horizontally; press Next; drag outward to resize.
