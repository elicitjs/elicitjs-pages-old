Zoom & pan

edit.axis.zoom() lets the wheel narrow or widen an axis's domain about the value under the pointer. edit.axis.pan() lets a drag slide it along. Both change the schema, like an editable axis: the dataset is unchanged, and scales, axes, marks and guides follow the new domain. chart.setDomain(field, domain) does the same from a button.

API reference

edit.axis.zoom(options)

The wheel narrows or widens the axis’s domain about the value under the pointer. It writes the schema’s domain, never the dataset. Place it on an axis: axes: { x: { edit: edit.axis.zoom() } }.

edit.axis.zoom({ factor, limit, minSpan, field, when }) → Edit
Options
OptionType · defaultDescription
factor
numberdefault1.2
How much one wheel notch (100 px of wheel travel) scales the span. Scrolling up divides the span by it; scrolling down multiplies.
limit
'declared' | [lo, hi] | falsedefault'declared'
The widest the domain may zoom out to: the field's domain as declared in the schema, an explicit range, or false for no limit.
minSpan
number
The narrowest span the domain may zoom in to, in data units.
field
stringdefaultevery field on the axis
The one field whose domain to write, when several fields share the axis.
when
(ctx) => boolean
Gate the zoom on a modifier key. when.alt on one axis and when.noAlt on the other zooms them separately.
Returns / emits

An Edit scoped to axis. It acts on a continuous scale (numeric or temporal). A burst of wheel ticks is one undo step.

edit.axis.pan(options)

Dragging the plot slides the axis’s domain along. It writes the schema’s domain, never the dataset, and composes with edit.axis.zoom() on the same axis: axes: { x: { edits: [edit.axis.zoom(), edit.axis.pan()] } }.

edit.axis.pan({ limit, field, when }) → Edit
Options
OptionType · defaultDescription

How far it may pan: the field's domain as declared in the schema, an explicit range, or false for no limit. At the limit the view stops and keeps its span.
field
stringdefaultevery field on the axis
The one field whose domain to write, when several fields share the axis.

(ctx) => boolean
Gate the pan on a modifier key, e.g. when.shift to pan only with Shift held.

An Edit scoped to axis. It acts on a continuous scale (numeric or temporal). A press on a mark with its own edit edits the mark. One drag is one undo step.

clip

A spec option. Clips the marks to the plot area, axis to axis. Only the part of a mark inside the clip takes a press or shows a tip. Axes, legends, guides and marks with clip: false keep drawing in the margins.

Elicit({ clip: { pad: 6 }, … })

chart.setDomain(field, domain, options)

Write a field’s domain from outside the chart — a zoom button, a reset control. The same commit a wheel tick or a pan makes: undoable, notified through change, and every scale reflows.

chart.setDomain("x", [20, 40])   // → true
chart.setDomain("x", null)       // restore the declared domain
chart.setDomain("weight", [0, 5], { table: "links" })
Options
OptionType · defaultDescription
field
string
The schema field to write. It writes that one field, as given.
domain
any[] | null
The new domain, or null for the domain declared in the schema.
options.table
stringdefaultthe primary table
The table that declares the field.
Returns / emits

true when it wrote the domain. false, with a warning, when the table declares no such field or there is no declared domain to restore.

Zoom with the wheel

Put edit.axis.zoom() on an axis in axes, one per axis you want to zoom. Scroll up to zoom in and down to zoom out. The value under the pointer stays where it is.

The declared domain is the zoom-out ceiling, so you can always scroll back to the full view and no further. Set limit to an explicit [lo, hi] for a different ceiling, or false for none.

A burst of wheel ticks is one step in history, so one undo restores the domain from before you scrolled. Each tick notifies change, and chart.getSchema() reads the current domain. The domain is the dataset's, so charts that share a dataset zoom together.

Zoom works on numeric and temporal axes. Mark edits keep working at every zoom level: drag a point and it inverts through the zoomed scale. The buttons call chart.setDomain for each axis (see below).

Zoom both axes

edit.axis.zoom() on x and y, plus buttons that zoom about the centre.

const chart = Elicit({
  width: 420, height: 280,
  margins: { top: 16, right: 18, bottom: 32, left: 40 },
  schema: {
    x: { type: "quantitative", domain: [0, 100] },
    y: { type: "quantitative", domain: [0, 100] },
  },
  data: [
    { x: 12, y: 20 }, { x: 24, y: 42 }, { x: 38, y: 35 }, { x: 47, y: 58 },
    { x: 55, y: 51 }, { x: 63, y: 70 }, { x: 71, y: 64 }, { x: 86, y: 82 },
  ],
  // The wheel zooms each axis about the value under the pointer.
  axes: {
    x: { edit: edit.axis.zoom() },
    y: { edit: edit.axis.zoom() },
  },
  marks: [
    point({
      fill: "#8A78C0", size: 6,
      channels: { x: { field: "x" }, y: { field: "y" } },
      edits: [move({ channels: ["x", "y"] })],
    }),
  ],
});
mount(chart.dom());

// Buttons zoom both axes about the centre of the view, clamped to the
// declared domains.
const DECLARED = { x: [0, 100], y: [0, 100] };
const zoomBy = (k) => {
  const schema = chart.getSchema();
  for (const field of ["x", "y"]) {
    const [lo, hi] = schema[field].domain;
    const [LO, HI] = DECLARED[field];
    const half = Math.min((hi - lo) * k, HI - LO) / 2;
    const mid = Math.min(Math.max((lo + hi) / 2, LO + half), HI - half);
    chart.setDomain(field, [mid - half, mid + half]);
  }
};

const controls = document.createElement("div");
controls.style.cssText = "display:flex;gap:8px;margin-top:10px;font:12px system-ui";
const addButton = (label, onclick) => {
  const b = document.createElement("button");
  b.textContent = label;
  b.onclick = onclick;
  b.style.cssText = "padding:4px 10px;border:1px solid #BCC9D4;border-radius:6px;background:#fff;cursor:pointer";
  controls.append(b);
};
addButton("Zoom in", () => zoomBy(0.5));
addButton("Zoom out", () => zoomBy(2));
addButton("Reset", () => { chart.setDomain("x", null); chart.setDomain("y", null); });
mount(controls);
Try: Scroll over the plot or click Zoom in · drag a point at any zoom level.

Pan by dragging

Add edit.axis.pan() to the same axis. Drag the plot and the domain follows the pointer. A pan on x follows horizontal travel and a pan on y follows vertical travel, so a pan on both moves the view diagonally.

A press on a mark with an edit of its own still edits that mark. A press anywhere else on the plot pans.

Pan stops at the declared domain, keeping the span. Set limit as on zoom. One drag is one undo step.

Zoom and pan write the same domain, so they combine. Each starts from where the other left it, and you can scroll to zoom in the middle of a drag.

Zoom and pan a year of data

edit.axis.zoom() and edit.axis.pan() on x. The buttons zoom about the centre of the view.

// A year of weekly rainfall. Zoom in, then drag the plot to pan along it.
const data = d3.range(53).map((week) => ({
  week,
  rain: Math.round(40 + 25 * Math.sin(week / 8) + 10 * Math.cos(week / 3)),
}));

const chart = Elicit({
  width: 460, height: 260,
  margins: { top: 16, right: 18, bottom: 32, left: 40 },
  schema: {
    week: { type: "quantitative", domain: [0, 52] },
    rain: { type: "quantitative", domain: [0, 100] },
  },
  data,
  // Zoom and pan both write the week domain, so each picks up where the
  // other left off.
  axes: {
    x: { edits: [edit.axis.zoom({ minSpan: 4 }), edit.axis.pan()] },
  },
  marks: [
    lineY({ stroke: "#2B5D87", strokeWidth: 2, channels: { x: { field: "week" }, y: { field: "rain" } } }),
    point({
      fill: "#2B5D87", size: 4,
      channels: { x: { field: "week" }, y: { field: "rain", edit: move() } },
    }),
  ],
});
mount(chart.dom());

const [LO, HI] = [0, 52];   // the declared week domain
const zoomBy = (k) => {
  const [lo, hi] = chart.getSchema().week.domain;
  const half = Math.max(2, Math.min((hi - lo) * k, HI - LO) / 2);
  const mid = Math.min(Math.max((lo + hi) / 2, LO + half), HI - half);
  chart.setDomain("week", [mid - half, mid + half]);
};

const controls = document.createElement("div");
controls.style.cssText = "display:flex;gap:8px;align-items:center;margin-top:10px;font:12px system-ui";
const addButton = (label, onclick) => {
  const b = document.createElement("button");
  b.textContent = label;
  b.onclick = onclick;
  b.style.cssText = "padding:4px 10px;border:1px solid #BCC9D4;border-radius:6px;background:#fff;cursor:pointer";
  controls.append(b);
};
addButton("Zoom in", () => zoomBy(0.5));
addButton("Zoom out", () => zoomBy(2));
addButton("Reset", () => chart.setDomain("week", null));
const readout = document.createElement("span");
readout.style.color = "#6F8294";
controls.append(readout);
mount(controls);

const show = () => {
  const [lo, hi] = chart.getSchema().week.domain;
  readout.textContent = `weeks ${lo.toFixed(1)} – ${hi.toFixed(1)}`;
};
chart.on("change", show);
show();

Clip to the plot

A zoomed or panned chart clips its marks to the plot area, axis to axis. A mark past an axis is hidden, and only the part inside the plot takes a press or shows a tip. Axes, legends and guides keep drawing in the margins.

Clipping is on by default whenever an axis carries edit.axis.zoom() or edit.axis.pan(). Set clip: false on the spec to turn it off, or clip: true to clip a chart with neither.

clip: { pad: 6 } clips to the plot area grown by 6 pixels, so a point on the edge of the domain draws whole. Pass one number for every side, or { top, right, bottom, left } for each side. A pad turns clipping on.

Set clip: false on a mark to draw it past the clip, such as a label in the margin. Its marks take a press and show a tip out there too. On a composite, it applies to every part.

Pad the clip, label in the margin

clip: { pad: 6 } on the spec and clip: false on the text mark.

// Daily highs that touch both ends of the scale. `pad` lets a point on the
// edge draw whole; `clip: false` keeps the latest reading's label in the margin.
const data = d3.range(30).map((day) => ({
  day,
  high: Math.max(0, Math.min(40, Math.round(20 + 18 * Math.sin(day / 3) + 6 * Math.cos(day)))),
}));

const W = 460, H = 260;
const margins = { top: 16, right: 72, bottom: 32, left: 40 };

const chart = Elicit({
  width: W, height: H, margins,
  schema: {
    day: { type: "quantitative", domain: [0, 29] },
    high: { type: "quantitative", domain: [0, 40] },
  },
  data,
  // Clip to the plot, grown by 6 px on every side.
  clip: { pad: 6 },
  axes: {
    x: { edits: [edit.axis.zoom({ minSpan: 5 }), edit.axis.pan()] },
  },
  marks: [
    lineY({ stroke: "#EE7B5E", strokeWidth: 2, channels: { x: { field: "day" }, y: { field: "high" } } }),
    point({
      fill: "#EE7B5E", size: 6,
      channels: { x: { field: "day" }, y: { field: "high", edit: move() } },
    }),
    // Pinned 8 px past the plot's right edge, at the latest day's value.
    // `clip: false` lets it draw in the margin.
    text({
      clip: false, textAnchor: "start", fontSize: 12, fill: "#B14A30",
      channels: {
        x: { value: W - margins.left - margins.right + 8 },
        y: { field: "high" },
        text: { fn: (d, i, rows) => (i === rows.length - 1 ? `${d.high}° today` : "") },
      },
    }),
  ],
});
mount(chart.dom());
Try: Scroll to zoom · drag the plot to pan · drag the last point and its label follows.

One axis at a time

A plain wheel zooms every axis carrying edit.axis.zoom(). Give each a when to split them by modifier key: when.noAlt on one axis and when.alt on the other.

minSpan sets the narrowest the domain may zoom in to, in data units. Here time stops at three months and value at ten units.

Time with the wheel, value with Alt

when.noAlt on x and when.alt on y; minSpan caps how far each zooms in.

// A forecast over 24 months. The plain wheel zooms time; Alt + wheel zooms the value.
const data = d3.range(25).map((m) => ({
  month: m,
  value: 50 + 20 * Math.sin(m / 4) + m * 0.8,
}));

const chart = Elicit({
  width: 440, height: 260,
  margins: { top: 16, right: 18, bottom: 32, left: 40 },
  schema: {
    month: { type: "quantitative", domain: [0, 24] },
    value: { type: "quantitative", domain: [0, 100] },
  },
  data,
  axes: {
    x: { edit: edit.axis.zoom({ when: when.noAlt, minSpan: 3 }) },
    y: { edit: edit.axis.zoom({ when: when.alt, minSpan: 10 }) },
  },
  marks: [
    lineY({
      stroke: "#1B3F60", strokeWidth: 2,
      channels: {
        x: { field: "month" },
        y: { field: "value", edit: move() },
      },
    }),
  ],
});
mount(chart.dom());
Try: Scroll to zoom time · Alt + scroll to zoom value · drag a point on the line.

Set a domain from outside

chart.setDomain(field, domain) writes a field's domain. It takes the same path as a wheel tick or a pan: one undo step, a change notification, and every scale reflows. Pass null to restore the domain declared in the schema.

setDomain returns false and logs a warning when the table declares no such field. Pass { table } to name a field of a table other than the primary one.

It writes the domain as given. Clamp to the declared domain yourself when zooming out, as the buttons above do:

const zoomBy = (k) => {
  const [lo, hi] = chart.getSchema().week.domain;
  const half = Math.min((hi - lo) * k, 52) / 2;
  const mid = Math.min(Math.max((lo + hi) / 2, half), 52 - half);
  chart.setDomain("week", [mid - half, mid + half]);
};
