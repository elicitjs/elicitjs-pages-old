External controls

Drive a chart from a control outside it: an input, a <select>, a slider, a rotate icon or a plain function. set(field, value, { index }) writes a value straight into the dataset. chart.control(name).set(value) replays a gesture through a named edit and the chart's scales. Both run constraints and undo, and fire on("change").

API reference

set(field, value, options?)

A dataset method, carried by every chart: write one cell from outside any chart. It runs the dataset’s constraints, then the lock, as an edit does; an edit’s own constrain does not run. One undo step; fires change and redraws every chart on the dataset. See Datasets & linked charts.

chart.set("n", 62)                   // row 0 of the primary table
chart.set("n", "62", { index: 2 })   // stored as the number 62
ds.set("weight", 3, { index: 0, table: "links" })
Returns / emits

true when it commits. false when a constraint rejects it, the row is locked or the value is unchanged, and, with a warning, for an undeclared field, an index out of range or a value the field’s type can’t hold. Writes rows that exist; to add one, replay a create gesture with chart.emit, or call setData.

edit({ name }) · chart.control(name, index?)

Give any edit a name, then replay its gesture from outside the chart with chart.control(name). The control synthesizes the same events a pointer does on that chart and feeds them to the one dispatch — so constraints, the edit’s own constrain, undo, guides, and on("change") all run. A new input source, not a second interaction system.

move({ name: "move", channels: ["x", "y"] })   // name an edit
const h = chart.control("move", 0);   // handle bound to the edit + datum 0
h.set(value)          // one-shot write (value edit) …
h.set({ x, y })       // … or a data value per channel (positional edit)
h.begin(); h.set(v); h.end();   // live drag → ONE undo entry
h.fire()              // TRIGGER edit (cycle/remove/toggle) — fires its click gesture
h.emit(event)         // raw event passthrough, scoped to this feature/node
h.accepts()           // what the channel's scale allows
Options
OptionType · defaultDescription
edit.name
stringdefaultnull
The handle this edit answers to. An edit with no name stays pointer- and keyboard-driven.
control(name, index?)
→ EditControldefaultindex: 0
A handle bound to that edit and that row. Ask for it again after the data changes; it resolves the edit on each call.
h.set(value)
void
Write a data value. A scalar for a single-channel edit, or a map keyed by channel or field for a multi-channel one. Untouched axes hold their current position rather than teleporting. Drives a direct edit, or a nearest or sweep pick on the control's row. Other plane edits log a warning; use chart.emit for them.
h.begin() / h.end()
void
Bracket a live drag, so many set ticks collapse into one undo entry — exactly as a pointer drag does.
h.fire()
void
Trigger an edit that takes no value — cycle, remove, toggle. It dispatches the edit’s own gesture on the row.
h.accepts()
→ object | null
What the channel’s scale allows: { field, type, kind, temporal, invertible, domain, values, range }. values is the accepted set on a discrete channel and null on a continuous one, where domain is the accepted range — so a picker or slider can offer only valid choices.
h.emit(event)
void
A raw event, scoped to this edit's feature and node. The low-level route when you already hold pixels.
Returns / emits

Every route runs the ordinary dispatch, so a constraint gates an external write exactly as it gates a drag. External control is not a bypass.

set(options?)

The universal value edit: write a value into a channel's field — quantitative, colour, categorical, temporal. The commit-gesture counterpart to the positional edits, and what an external picker/slider drives via control(name).set(value). (editText is its text specialization.)

fill: { field: "group", edit: set({ name: "category" }) }
chart.control("category", i).set("B")

select() · chart.select · chart.selectWhere

Selection is transient pipeline state, not a selected data column. Put edit.select() on a mark to select it by click; drive the same state from outside with chart.select(index) (a specific item) or chart.selectWhere(field, value) (a category — the first matching row). The selected row gets the highlight outline, and a legend picker's row defaults to it. A select event fires; on("change")/getData never do.

edits: [ select() ]            // click a mark to select it
chart.select(2)                   // select a SPECIFIC item by index
chart.selectWhere("group", "North")  // select by CATEGORY (first match)
chart.getSelection()             // → index | null
chart.clearSelection()           // deselect all
chart.on("select", (i, all) => …)  // selection changed (no data moved)

chart.setDomain(field, domain, options)

Write a field’s domain from outside the chart — a zoom button, a reset control. The same commit a wheel zoom, a pan or an axis drag makes: one undo step, a change notification, and every scale reflows. Pass null to restore the declared domain. See Zoom & pan.

chart.setDomain("x", [20, 40])            // → true
chart.setDomain("x", null)                // restore the declared domain
chart.setDomain("weight", [0, 5], { table: "links" })

chart.emit(event)

Low-level: inject a renderer-shaped gesture event directly. x/y are inner (margin-subtracted) pixels. Prefer control, which computes pixels from a data value for you.

chart.emit({ type: "commit", node, value })
chart.emit({ type: "dragstart", node });  chart.emit({ type: "drag", node, x, y });  chart.emit({ type: "dragend", node })

Write a value with set

set(field, value, { index, table }) is a dataset method, and every chart carries it. It writes one cell, runs the dataset's constraints and then the lock, and is one undo step. index counts the rows getData() reports and defaults to 0. The value is stored as the field's type, so an input's "62" becomes the number 62. No edit runs, so set works on any declared field, with or without a chart. See Datasets & linked charts.

Type a value per bar

Each input calls chart.set("n", value, { index: i }). The clamp on the dataset caps a typed 95 at 80.

// `chart.set(field, value, { index })` writes one cell of the dataset. No edit
// is involved, so the bars need none for the inputs to work; `move()` is here so
// you can drag them too.
const quarters = ["Q1", "Q2", "Q3", "Q4"];
const chart = Elicit({
  width: 380, height: 220,
  margins: { top: 14, right: 16, bottom: 28, left: 36 },
  schema: {
    q: { type: "categorical",  domain: quarters },
    n: { type: "quantitative", domain: [0, 100] },
  },
  data: quarters.map((q) => ({ q, n: 40 })),
  // The dataset's rules hold for a typed value as they do for a drag.
  constraints: [clamp({ min: 0, max: 80, field: "n" })],
  marks: [
    barY({
      fill: "#50AEB7",
      channels: { x: { field: "q" }, y: { field: "n", edit: move() } },
    }),
  ],
});
mount(chart.dom());

const row = document.createElement("div");
row.style.cssText = "display:flex;gap:10px;flex-wrap:wrap;margin-top:10px;font:13px system-ui";
const inputs = quarters.map((q, i) => {
  const label = document.createElement("label");
  label.style.cssText = "display:flex;flex-direction:column;gap:2px;color:#6F8294";
  label.textContent = q;
  const input = document.createElement("input");
  input.type = "number"; input.min = 0; input.max = 100; input.style.width = "64px";
  // The input's value is a string; `set` stores it as the field's type.
  input.onchange = () => chart.set("n", input.value, { index: i });
  label.append(input);
  row.append(label);
  return input;
});
const sync = () => chart.getData().forEach((d, i) => { inputs[i].value = Math.round(d.n); });
chart.on("change", sync);
sync();
mount(row);
Try: Type a value under a quarter, or drag a bar.

Name an edit, then drive it

Use control when the write should act like the gesture: an edit's own constrain, a click edit such as cycle, a rotate about the mark. Give the edit a name, then call chart.control(name).

An edit maps a gesture to data by inverting a channel's scale. control(name).set(value) runs that scale forward to find the gesture, then runs the ordinary edit. A value edit (set, editText) takes the value directly, with no pixel step. control(name).accepts() reports what the channel's scale allows, so a picker or slider can offer only valid values.

A picker and a drag pad

The <select> writes the point's category through a set() edit. Its options come from control("category", 0).accepts().values. The pad drives a two-axis move live, and begin() … set({x,y}) … end() is one undo entry. The clamp on y limits the pad exactly as it limits a mouse drag.

Scatter: category picker + drag pad

A <select> sets the category; a draggable pad moves the point through the clamped drag edit.

// External controllers drive the SAME edits a pointer does. A `<select>` sets the
// category (a value edit); a draggable pad moves the point (a positional edit).
// Both go through the normal pipeline — the clamp on y holds for the pad exactly
// as it would for a mouse drag.
const chart = Elicit({
  width: 380, height: 260,
  margins: { top: 14, right: 14, bottom: 26, left: 30 },
  schema: {
    x:     { type: "quantitative", domain: [0, 100] },
    y:     { type: "quantitative", domain: [0, 100] },
    group: { type: "categorical",  domain: ["A", "B", "C"] },
  },
  data: [
    { x: 30, y: 40, group: "A" },
  ],
  // A dataset invariant: y can never exceed 80. It gates EVERY edit, including the
  // pad drag below — external control is not a bypass.
  constraints: [ clamp({ field: "y", max: 80 }) ],
  marks: [
    point({
      size: 7,
      channels: {
        x: { field: "x" },
        y: { field: "y" },
        fill: {
          field: "group",
          scale: { range: ["#50AEB7", "#315228", "#F2B94B"] },
          // A universal value edit: an external picker writes the chosen category.
          edit: set({ name: "category" }),
        },
      },
      // One drag over BOTH axes, named so a controller can address it.
      edits: [ move({ name: "move", channels: ["x", "y"] }) ],
    }),
  ],
});
mount(chart.dom());


// We drive datum 0 (the first point). `.accepts()` reads what the channel allows.
const i = 0;
const cats = chart.control("category", i).accepts().values;   // ["A","B","C"]
const [dx, dy] = [chart.getSchema().x.domain, chart.getSchema().y.domain];


const controls = document.createElement("div");
controls.style.cssText = "display:flex;gap:16px;align-items:center;margin-top:10px;font:12px system-ui";


// 1) Category picker — options come straight from the scale's accepted values.
const pick = document.createElement("select");
for (const c of cats) {
  const o = document.createElement("option");
  o.value = c; o.textContent = c; pick.append(o);
}
pick.value = chart.getData()[i].group;
pick.onchange = () => chart.control("category", i).set(pick.value);
const pickWrap = document.createElement("label");
pickWrap.style.cssText = "display:flex;gap:6px;align-items:center";
pickWrap.append("category", pick);


// 2) A draggable pad — the "UI element around the point". Dragging maps the pad's
// local position to data space and drives the `move` edit live: begin() … set() …
// end() collapse into ONE undo entry, just like a real drag.
const pad = document.createElement("div");
pad.style.cssText = "position:relative;width:120px;height:120px;border:1px solid #BCC9D4;border-radius:8px;background:#F6F9FB;touch-action:none;cursor:grab";
const knob = document.createElement("div");
knob.style.cssText = "position:absolute;width:14px;height:14px;margin:-7px 0 0 -7px;border-radius:50%;background:#14283A";
pad.append(knob);
const placeKnob = () => {
  const d = chart.getData()[i];
  knob.style.left = ((d.x - dx[0]) / (dx[1] - dx[0]) * 100) + "%";
  knob.style.top = (100 - (d.y - dy[0]) / (dy[1] - dy[0]) * 100) + "%";
};
let handle = null;
const toData = (ev) => {
  const r = pad.getBoundingClientRect();
  const fx = Math.max(0, Math.min(1, (ev.clientX - r.left) / r.width));
  const fy = Math.max(0, Math.min(1, (ev.clientY - r.top) / r.height));
  return { x: dx[0] + fx * (dx[1] - dx[0]), y: dy[0] + (1 - fy) * (dy[1] - dy[0]) };
};
pad.addEventListener("pointerdown", (ev) => {
  pad.setPointerCapture(ev.pointerId);
  handle = chart.control("move", i);
  handle.begin();
  handle.set(toData(ev));
});
pad.addEventListener("pointermove", (ev) => { if (handle) handle.set(toData(ev)); });
const stop = () => { if (handle) { handle.end(); handle = null; } };
pad.addEventListener("pointerup", stop);
pad.addEventListener("pointercancel", stop);


const padWrap = document.createElement("div");
padWrap.style.cssText = "display:flex;flex-direction:column;gap:4px;align-items:center;color:#6F8294";
padWrap.append(pad, document.createTextNode("drag to move point 0"));


controls.append(pickWrap, padWrap);
mount(controls);


// Keep the picker + knob in sync with committed data (edits, undo, redo all fire).
chart.on("change", () => { pick.value = chart.getData()[i].group; placeKnob(); });
placeKnob();
Try: pick a category; drag the pad; the point obeys the y ≤ 80 clamp either way.

Pick vs. cycle: driving other gestures

.set(value) drives the value edits (set, editText) and the positional ones (move, rotate, resize). The click edits (cycle, remove, toggle) take no value. .fire() drives them by running the edit's own gesture on the row. One circle can offer a picker (set, to jump to a value) and a cycle (fire, to step to the next) on the same field, beside the native click.

A circle: pick or cycle its category

A dropdown sets the category (set); a button and the circle itself step it (cycle).

// Two ways to change one circle's category, both external. `cycle` is a CLICK edit
// that steps to the next value; a picker SETS a value directly. They coexist on the
// same `fill` field: click the circle (or the ⟳ button) to step, or choose from the
// dropdown to jump straight there.
const chart = Elicit({
  width: 300, height: 190,
  margins: { top: 10, right: 10, bottom: 10, left: 10 },
  schema: {
    kind: { type: "categorical", domain: ["low", "med", "high"] },
  },
  data: [ { kind: "low" } ],
  marks: [
    point({
      size: 26,
      channels: {
        x: { value: 150 },
        y: { value: 90 },
        fill: {
          field: "kind",
          scale: { range: ["#B7DEE1", "#50AEB7", "#50AEB7"] },
          // Direct choice — a picker writes exactly this value.
          edit: set({ name: "pick" }),
        },
      },
      // Step-at-a-time — a click (on the circle or a button) advances the category.
      edits: [ cycle({ name: "step", channel: "fill" }) ],
    }),
  ],
});
mount(chart.dom());

const controls = document.createElement("div");
controls.style.cssText = "display:flex;gap:12px;align-items:center;margin-top:10px;font:13px system-ui";

// A picker → `set`: options are exactly the values the fill scale accepts.
const pick = document.createElement("select");
for (const v of chart.control("pick", 0).accepts().values) {
  const o = document.createElement("option");
  o.value = v; o.textContent = v; pick.append(o);
}
pick.value = chart.getData()[0].kind;
pick.onchange = () => chart.control("pick", 0).set(pick.value);
const pickWrap = document.createElement("label");
pickWrap.style.cssText = "display:flex;gap:6px;align-items:center";
pickWrap.append("pick", pick);

// A button → `fire`: dispatches the cycle edit's own click gesture, no value.
const step = document.createElement("button");
step.textContent = "⟳ cycle";
step.onclick = () => chart.control("step", 0).fire();

controls.append(pickWrap, step);
mount(controls);

// Keep the picker in step whichever way the category changed.
chart.on("change", () => { pick.value = chart.getData()[0].kind; });
Try: choose from the dropdown, press ⟳, or click the circle — all change the same field.

Sliders for facial features

Each facial parameter is a channel. Bind it to a field with a named set() edit and a slider can write it. The face stays draggable: grab the mouth to pull a smile. Each slider's range comes from control(field).accepts().domain.

Face: parameter sliders

Three sliders drive three facial params; dragging the face keeps them in sync.

// A face is a row of fields; each facial PARAM is a channel on one of the face's
// parts. Bind each to a field with a named `set()` edit and an external slider can
// write it. `.accepts()` reads the range off the very scale the part encodes
// through — including a group's per-datum FRAME scale — so the slider offers
// exactly the values the channel accepts. Add a `slide`/`rotate` alongside and the
// same field is drivable by pointer too: one dataset, two input sources.
const PARAMS = [
  { param: "mouthCurve", field: "smile", label: "smile" },
  { param: "eyeScale",   field: "eyes",  label: "eyes"  },
  { param: "browTilt",   field: "brow",  label: "brow"  },
];

const channels = {};
for (const { param, field } of PARAMS) {
  channels[param] = { field, edit: set({ name: field }) };
}

const chart = Elicit({
  width: 300, height: 300,
  margins: { top: 12, right: 12, bottom: 12, left: 12 },
  schema: {
    smile: { type: "quantitative", domain: [0, 1] },
    eyes:  { type: "quantitative", domain: [0, 1] },
    brow:  { type: "quantitative", domain: [0, 1] },
  },
  data: [ { smile: 0.7, eyes: 0.5, brow: 0.4 } ],
  marks: [ face({ channels }) ],
});
mount(chart.dom());

const controls = document.createElement("div");
controls.style.cssText = "display:flex;flex-direction:column;gap:8px;margin-top:10px;font:12px system-ui;max-width:300px";

const sliders = {};
for (const { field, label } of PARAMS) {
  // `.accepts()` tells the UI the field's range (from the scale/schema), so the
  // slider offers only values the channel accepts.
  const [lo, hi] = chart.control(field).accepts().domain;
  const row = document.createElement("label");
  row.style.cssText = "display:grid;grid-template-columns:48px 1fr;gap:8px;align-items:center";
  const s = document.createElement("input");
  s.type = "range"; s.min = lo; s.max = hi; s.step = (hi - lo) / 100;
  s.value = chart.getData()[0][field];
  s.oninput = () => chart.control(field).set(+s.value);
  sliders[field] = s;
  row.append(label, s);
  controls.append(row);
}
mount(controls);

// Dragging the face directly also fires `change` — keep the sliders in step.
chart.on("change", () => {
  const d = chart.getData()[0];
  for (const { field } of PARAMS) sliders[field].value = d[field];
});
Try: move a slider, or drag the face directly — both write the same fields.

A rotate icon for a box

rotate reads a pointer angle about the mark. control("spin", 0).set(deg) encodes the angle to the pointer position that would produce it, then runs the ordinary rotate edit. The box also rotates by direct drag.

Rotate a box by an icon

Buttons step the angle in data space; the control encodes each angle for the rotate edit.

// A rotate icon spins a box. `rotate` is a positional edit — it reads a pointer
// angle about the mark. Driving it by a DATA value (degrees) is just the inverse:
// `.set(deg)` forward-encodes the angle to the pointer that would produce it, then
// runs the ordinary edit. The box is also directly rotatable by dragging it.
const chart = Elicit({
  width: 300, height: 260,
  margins: { top: 20, right: 20, bottom: 20, left: 20 },
  schema: {
    x:     { type: "quantitative", domain: [0, 100] },
    y:     { type: "quantitative", domain: [0, 100] },
    theta: { type: "quantitative", domain: [0, 360] },
  },
  data: [ { x: 50, y: 50, theta: 20 } ],
  marks: [
    rect({
      channels: {
        x: { field: "x" },
        y: { field: "y" },
        width:  { value: 90 },
        height: { value: 60 },
        fill: { value: "#50AEB7" },
        stroke: { value: "#37919B" },
        angle: {
          field: "theta",
          scale: { range: [0, 360] },
          edit: rotate({ name: "spin", pick: "direct", pivot: "mark", fold: false }),
        },
      },
    }),
  ],
});
mount(chart.dom());

const controls = document.createElement("div");
controls.style.cssText = "display:flex;gap:8px;align-items:center;margin-top:10px;font:13px system-ui";

const spinBy = (delta) => {
  const now = chart.getData()[0].theta;
  const next = ((now + delta) % 360 + 360) % 360;
  chart.control("spin", 0).set(next);   // forward-encodes deg -> pointer -> rotate
};

const ccw = document.createElement("button");
ccw.textContent = "⟲ −15°";
ccw.onclick = () => spinBy(-15);
const cw = document.createElement("button");
cw.textContent = "⟳ +15°";
cw.onclick = () => spinBy(15);

const readout = document.createElement("span");
readout.style.cssText = "color:#6F8294";
const sync = () => { readout.textContent = Math.round(chart.getData()[0].theta) + "°"; };
chart.on("change", sync);
sync();

controls.append(ccw, cw, readout);
mount(controls);
Try: press the rotate buttons, or drag the box itself.

Sweep and nearest edits

control(name, index) names its row, so it also drives an edit whose pick only chooses a row: nearest and sweep. .set(v) writes row index, whichever row the pointer would have found. An edit that needs a pointer path or position, such as edit.line.draw(), a brush or create(), logs a warning and writes nothing. Drive those with chart.emit({ type, x, y }) in plot pixels.

Type or sweep a forecast

One move({ pick: "sweep", name: "forecast" }) edit takes both the sweep and the inputs.

// A you-draw-it line takes its answer two ways: sweep across the chart, or type
// a value per year. `move({ pick: "sweep" })` finds the row under the pointer;
// `control("forecast", i)` names the row itself, so `.set(v)` writes year i.
const years = [2024, 2025, 2026, 2027, 2028];
const chart = Elicit({
  width: 420, height: 240,
  margins: { top: 14, right: 14, bottom: 26, left: 30 },
  axes: { x: { tickFormat: "d" } },
  schema: {
    year: { type: "quantitative", domain: [2024, 2028] },
    v:    { type: "quantitative", domain: [0, 100] },
  },
  data: years.map((year) => ({ year, v: 50 })),
  marks: [
    lineY({
      stroke: "#50AEB7", strokeWidth: 2.5,
      channels: {
        x: { field: "year" },
        y: { field: "v", edit: move({ pick: "sweep", name: "forecast" }) },
      },
    }),
  ],
});
mount(chart.dom());

const row = document.createElement("div");
row.style.cssText = "display:flex;gap:10px;flex-wrap:wrap;margin-top:10px;font:13px system-ui";
const inputs = years.map((year, i) => {
  const label = document.createElement("label");
  label.style.cssText = "display:flex;flex-direction:column;gap:2px;color:#6F8294";
  label.textContent = year;
  const input = document.createElement("input");
  input.type = "number"; input.min = 0; input.max = 100; input.style.width = "64px";
  input.onchange = () => chart.control("forecast", i).set(Number(input.value));
  label.append(input);
  row.append(label);
  return input;
});
const sync = () => chart.getData().forEach((d, i) => { inputs[i].value = Math.round(d.v); });
chart.on("change", sync);
sync();
mount(row);

Driving the selection

The selection is interface state, kept beside the data, so it has its own API and its own select event. chart.select(index) picks a specific row. chart.selectWhere(field, value) picks by category: the first matching row, or every match with { all: true }. Both set the selection as a click with edit.select() does. The selected row gets the highlight outline, and a legend picker edits it. on("select") reports the change. getData and on("change") stay silent, because no answer data changed.

Pass an array to chart.select for several rows at once. See Selection for multi-select, the selected effect and the edits that read the selection.

Select an item, or a category

A dropdown selects a specific bar; a button selects the first bar in a group; the legend edits whichever is selected.

// Selection is pipeline state, so it has its own external API beside the data —
// no `selected` column. `el.select(index)` picks a SPECIFIC ITEM; `el.selectWhere`
// picks by CATEGORY (the first row matching a field/value). Clicking a bar selects
// it too (edit.select), and `on("select")` reports whichever way it moved. The
// legend then edits the SELECTED bar's group.
const chart = Elicit({
  width: 360, height: 210,
  margins: { top: 16, right: 16, bottom: 28, left: 36 },
  data: [
    { name: "A", value: 12, group: "North" },
  ],
  schema: {
    name: { type: "categorical", domain: ["A", "B", "C", "D"] },
    group: { type: "categorical", domain: ["North", "South"] },
    value: { type: "quantitative", domain: [0, 16] },
  },
  marks: [
    barY({
      channels: {
        x: { field: "name" },
        y: { field: "value" },
        fill: { field: "group" },
      },
      edits: [ select() ],           // click a bar to select it
    }),
    legendColor({ anchor: "right", title: "group", edit: edit.legend.category() }),
  ],
});
mount(chart.dom());


const controls = document.createElement("div");
controls.style.cssText = "display:flex;gap:12px;align-items:center;flex-wrap:wrap;margin-top:10px;font:13px system-ui";


// Select a SPECIFIC ITEM by its name (→ el.selectWhere on the `name` field).
const item = document.createElement("select");
for (const d of chart.getData()) {
  const o = document.createElement("option");
  o.value = d.name; o.textContent = d.name; item.append(o);
}
item.onchange = () => chart.selectWhere("name", item.value);
const itemWrap = document.createElement("label");
itemWrap.style.cssText = "display:flex;gap:6px;align-items:center";
itemWrap.append("item", item);


// Select a CATEGORY — the first bar in a group (→ el.selectWhere on `group`).
const cat = document.createElement("select");
for (const g of ["North", "South"]) {
  const o = document.createElement("option");
  o.value = g; o.textContent = g; cat.append(o);
}
const catBtn = document.createElement("button");
catBtn.textContent = "select group";
catBtn.onclick = () => chart.selectWhere("group", cat.value);
const catWrap = document.createElement("label");
catWrap.style.cssText = "display:flex;gap:6px;align-items:center";
catWrap.append("group", cat, catBtn);


// Clear.
const clear = document.createElement("button");
clear.textContent = "clear";
clear.onclick = () => chart.clearSelection();


const readout = document.createElement("span");
readout.style.cssText = "margin-left:auto;color:#6F8294";


controls.append(itemWrap, catWrap, clear, readout);
mount(controls);


// on("select") hears selection changes — never `change`, since no data moved.
chart.on("select", (i) => {
  const d = i == null ? null : chart.getData()[i];
  readout.textContent = d ? `selected: ${d.name} (${d.group})` : "nothing selected";
  if (d) item.value = d.name;
});
readout.textContent = "nothing selected";
Try: pick an item or a group — or click a bar — then use the legend to change its group.

Driving a domain

chart.setDomain(field, domain) writes a field's domain from outside the chart, for a zoom button or a "reset view" control. It commits like edit.axis.zoom() and edit.axis.pan(): one undo step, a change notification, and every scale updates. Pass null to restore the domain declared in the schema.

chart.setDomain("x", [20, 40]);   // zoom to 20–40
chart.setDomain("x", null);       // back to the declared domain

See Zoom & pan for buttons that zoom in, zoom out and reset.
