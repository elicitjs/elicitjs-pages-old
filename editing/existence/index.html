Row lifecycle & lock

These edits add and remove rows. create() inverts a click into a new row, and remove() deletes the clicked row. lock makes given rows read-only, and context marks given rows as reference, left out of your answer.

API reference

What can — and cannot — be created

Creation writes dataset rows, so it goes on a data mark with an invertible positional axis. Elements and guides write no rows. trend draws one line from a row's intercept and slope, so it has no position to invert.

MarkCreate?How
point · shape✓Invert pointer through x and y
tick · bar✓One axis inverts to a band slot, the other to value
rule✓Invert pointer on its value axis
rect✓Seed default extents (x1/x2 or y1/y2)
composite (glyph)✓Create on one component mark; row renders across all
line · path✓Series-aware anchor and draw edits
Elements: axisX · gridY · legendColor✗Edit the scale's domain, not rows
Guides: guides.*✗Write nothing
trend✗A parametric line drawn from one row; no position to invert

Create — click to add

create() inverts a click on empty space into a new row and appends it. A constraint such as count({ max }) caps the number of rows.

Declare a creator on one mark only. Each mark on the table that carries one appends a row on the same click.

Click to add a point

create({ defaults }) mints a datum at the pointer; count({ max: 8 }) caps the dataset.

const chart = Elicit({
  width: 380, height: 260,
  margins: { top: 14, right: 14, bottom: 26, left: 30 },
  data: [{ x: 30, y: 30, group: "a" }],
  schema: {
    // Declared so create() mints it on a new row — an undeclared column would be
    // missing from every point the click adds.
    group: { type: "categorical" },
    x: { type: "quantitative", domain: [0, 100] },
    y: { type: "quantitative", domain: [0, 100] },
  },
  constraints: [ count({ max: 8 }) ],   // dataset invariant: at most 8
  marks: [
    point({
      fill: "#1B3F60",
      size: 8,
      channels: {
        x: { field: "x", edit: move() },
        y: { field: "y", edit: move() },
      },
      edits: [ create({ defaults: { group: "a" } }) ],
    }),
  ],
});
mount(chart.dom());
Try: Click empty space to add a point · drag to move it.

Create, move & remove arbitration

remove() fires on a plain click. When several edits share a mark, split their gestures with when: for example, double-click to add, drag to move and Alt+click to remove.

Create, move, and remove on one mark

Double-click adds, Alt-click deletes, and drag moves.

const chart = Elicit({
  width: 380, height: 260,
  margins: { top: 14, right: 14, bottom: 26, left: 30 },
  data: [{ x: 30, y: 40 }, { x: 65, y: 65 }],
  schema: {
    s: { type: "categorical" },  // the series key; declared so create() mints it
    x: { type: "quantitative", domain: [0, 100] },
    y: { type: "quantitative", domain: [0, 100] },
  },
  marks: [
    point({
      fill: "#1B3F60",
      size: 8,
      channels: {
        x: { field: "x" },
        y: { field: "y" },
      },
      edits: [
        move({ channels: ["x", "y"] }),
        create({ gesture: "dblclick" }),
        remove({ when: when.alt }),
      ],
    }),
  ],
});
mount(chart.dom());
Try: Double-click to add · Alt+click to delete · Drag to move.

Arbitration between click actions

when.noAlt cycles color; when.alt removes the row.

const chart = Elicit({
  width: 380, height: 260,
  margins: { top: 14, right: 14, bottom: 26, left: 30 },
  data: [
    { x: 25, y: 40, group: "alpha" },
  ],
  schema: {
    s: { type: "categorical" },  // the series key; declared so create() mints it
    x:     { type: "quantitative", domain: [0, 100] },
    y:     { type: "quantitative", domain: [0, 100] },
    group: { type: "categorical", domain: ["alpha", "beta", "gamma"] },
  },
  marks: [
    point({
      size: 10,
      channels: {
        x: { field: "x", edit: move() },
        y: { field: "y", edit: move() },
        fill: { field: "group", edit: cycle({ when: when.noAlt }) },
      },
      edits: [ remove({ when: when.alt }) ],
    }),
  ],
});
mount(chart.dom());
Try: Click a dot to recolour · Alt+click to delete.

Locked seed data, free additions

lock: "seed" makes the rows you passed as data read-only. Rows that create() adds stay editable. See Locked rows.

Locking rows by predicate

A predicate locks rows by their fields, such as actuals beside a forecast. See Locked rows.

Context rows

A locked row is still part of your answer: getData() returns it. When the given rows are only for reference, mark them as context instead. context: true makes every row in data context. A predicate picks the rows it accepts (context: (d) => d.year <= 2020).

Context rows belong to the same table, so they share its columns and schema. Every mark over the table draws them, and they are read-only, like locked rows. getData() and onChange leave them out, so a one-table chart still reports a bare array of your answers. The selection API and control() count reported rows only, so getData()[i] and select(i) name the same row.

The predicate runs once, over the rows in data. A row you add or drag later stays part of your answer, even when the predicate would accept it. setData(rows) replaces your answers and keeps the context rows. Constraints see context rows too, because they are rows of the table.

When the reference rows carry other columns (an observed price beside your lo and hi), declare all of them in the schema. Each row fills its own columns, and a mark skips a row whose value is missing. Reference data unrelated to the answer is a guide.

The record as context, the forecast as your answer

2010–2020 is context: drawn and read-only. getData() returns only the four forecast years.

const chart = Elicit({
  width: 440, height: 260,
  margins: { top: 16, right: 16, bottom: 32, left: 40 },
  axes: { x: { tickFormat: "d" } },
  schema: {
    year: { type: "quantitative", domain: [2010, 2030] },
    rate: { type: "quantitative", domain: [0, 10] },
  },
  // 2010–2020 is the record; 2022–2030 is your forecast.
  data: [
    { year: 2010, rate: 4.2 }, { year: 2012, rate: 4.8 }, { year: 2014, rate: 5.1 },
  ],
  // The record is context: drawn and read-only, but not part of your answer.
  context: (d) => d.year <= 2020,
  guides: [guides.region({ x: [2010, 2020], fill: "#94A5B3", opacity: 0.12 })],
  marks: [
    lineY({
      stroke: "#50AEB7", strokeWidth: 2,
      channels: {
        x: { field: "year" },
        y: { field: "rate", edit: move() },
      },
    }),
  ],
});
mount(chart.dom());
Try: Drag a forecast point (2022–2030). The record does not move.
